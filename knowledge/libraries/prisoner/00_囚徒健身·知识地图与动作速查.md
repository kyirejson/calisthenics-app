## ⚠️ 训练安全与内容审核说明

《囚徒健身》具有系统化的自重进阶思想，但原书成书具有强烈的个人经验与特殊环境背景。在参考原书或进行产品化转化时，建议遵循以下客观分类与安全原则：

```text
┌──────────────────────────────────────────────────────────────────────────┐
│                           自重动作适用性分类参考                          │
├───────────────────┬──────────────────────────────────────────────────────┤
│ 🟢 低难度入门候选  │ 墙壁/上斜推、水平拉、支撑深蹲、屈膝屈髋等基础动作      │
│ 🟡 需严格前置条件  │ 指尖支撑、顺风旗、杠杆类动作、大幅度单侧进阶           │
│ 🔴 限制或排除动作  │ 头颈承重动作（如颈桥）、无防护翻腾（空翻/打挺）、单臂倒立 │
└───────────────────┴──────────────────────────────────────────────────────┘
```

1. **头颈承重与高难度动作的隔离**
   - **摔跤手颈桥（第二册第十章）**：正文主张颈椎直接接触地面滚动承重。由于颈椎活动度大、稳定性弱，在轴向负荷下极易发生急性错位或劳损。产品首版不将此类颈部负重练习作为推荐计划，建议以无痛范围内的四向自抗力等长练习作为低负荷替代。
   - **顶桥（第一册第九章第四式）**：第一册正文明确要求四肢推起、头顶仅轻触地面辅助平衡。注意：**顶桥不等于颈桥**，但因包含头部触地和大幅度后伸，对腕部、胸椎及控制力要求仍高，不适合直接作为无基础者的默认计划。
   - **空翻与打挺（第三册第七、八章）**：属于高技巧体操动作，对场地缓冲（体操垫/海绵池）和专业保护人员有极高要求，缺乏防护条件时不应作为常规居家训练。
   - **垂直推进阶选择（第一册第十章）**：涉及倒立支撑的练习对肩腕柔韧性与心血管负荷有较高要求；训练者应按自身条件选择推力练习，不设立所有人必须达到的倒立终点。

2. **关节恢复与“疗伤”边界澄清**
   - **原书定位**：第二册第二十章《疗伤八法》包含关于布洛芬、阿司匹林、扑热息痛等非甾体抗炎药的个人经验论述，以及通过特定练习加速恢复的断言。
   - **产品规范**：产品不采纳原书中的任何用药判断，不提供医疗康复处方；第二册三诀（桥式、直角式、扭转式）仅作为适用人群在无痛状态下的一般性活动度练习。出现急性红肿热痛、刺痛锐痛或下肢发麻等神经受压症状，必须立即停止训练并就医。

3. **营养与增肌参考的科学依据**
   - **原书观点留存**：第四册第二章、第七章中包含用恶心感代表强度、睡眠越多越好、依赖高脂食物提升睾酮与增肌等表述，仅作为原书文献留存，产品设计不予采纳。
   - **循证参考标准**：根据国际运动营养学会（[ISSN 立场文件 2017](https://link.springer.com/article/10.1186/s12970-017-0177-8)），健康运动成年人全天总蛋白质参考摄入量为 **1.4～2.0 g/kg/天**。此数值为全天膳食总摄入参考，优先通过天然食物满足，不作为需要个别指导人群（如肾功能不全、孕期）的处方。日常饮食遵循《中国居民膳食指南》的多样与均衡原则。
