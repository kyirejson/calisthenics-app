# 🦠 食品安全防护与HACCP管理体系

> “营养的底线是安全。一次致病菌感染，足以摧毁最完美的营养干预方案。”
> 
> “控制温度与防交叉污染，是厨房里最核心的医学纪律。” —— CDC 临床营养安全指南

## 🦠 食源性致病菌与微生物风险防线

微生物污染是食源性疾病的最主要推手。精准识别致病菌的“宿主”与“弱点”，是营养师制定安全备餐方案的前提。

| 致病菌种类 | 常见高危食物来源 | 临床特征与危害 | 营养师干预/防护要点 |
| :--- | :--- | :--- | :--- |
| **沙门氏菌** *(Salmonella)* | 未煮熟的禽肉、生鸡蛋（蛋壳及内部）、生牛奶 | 腹泻、发烧、腹部绞痛（潜伏期 6-72 小时） | 拒绝生食鸡蛋（除非使用巴氏杀菌蛋）；禽类烹饪中心温度需达标。 |
| **李斯特菌** *(Listeria)* | 冷藏熟食（如热狗、切片冷肉）、软奶酪、生乳制品 | 能够在 4℃ 冷藏环境下繁殖；**孕妇杀手**（可穿透胎盘屏障导致流产或死胎） | 孕妇严格禁食未经加热的高危冷餐熟肉与软奶酪；剩菜彻底加热。 |
| **金黄色葡萄球菌** *(Staph)* | 频繁手工接触且无需再加热的食物（沙拉、糕点） | 细菌产生的**耐热肠毒素**无法被常规烹饪破坏 | 厨师手部带有伤口或化脓性感染时绝对禁止接触食物。 |
| **副溶血性弧菌** *(V. parahaemolyticus)* | 生海鲜、生蚝、未煮熟的贝类 | 剧烈水样腹泻，夏秋季高发 | 避免生食海鲜；接触生海鲜的案板必须彻底消毒防交叉污染。 |
| **肉毒杆菌** *(C. botulinum)* | 自制发酵食品、胀气或密封不严的低酸罐头、蜂蜜 | 产生极毒的肉毒素，导致神经麻痹甚至呼吸衰竭 | 婴儿1岁前绝对禁食蜂蜜；废弃所有胀袋、漏气罐头；自制发酵严格控制 pH 值。 |

## 🌡️ 温度控制与危险法则

微生物在适宜的温度下呈对数级繁殖。食品安全的本质是“与时间赛跑”。

### 温度危险区 (Danger Zone)
- **危险区间**：**4℃ - 60℃** (40℉ - 140℉)
- **致病机制**：在此温度带内，大多数致病菌可以每 20 分钟繁殖一代。

### 两小时危险法则
- 处于危险区间的食物，**极限安全时间为 2 小时**（如果在室温 >32℃ 的炎热环境下，极限时间缩短为 **1 小时**）。
- 超过限时的食物必须丢弃，不能通过再次加热来“挽救”（因为耐热毒素可能已形成）。

### 核心温度指标
- **再加热**：中心温度必须达到 **≥ 74℃ (165℉)**。
- **禽肉类**：中心温度需达 **≥ 74℃**。
- **碎肉（如汉堡肉饼）**：中心温度需达 **≥ 71℃ (160℉)**（因绞肉过程将表面细菌卷入内部）。

## 🛡️ 交叉污染防护与厨房动线

交叉污染 (Cross-contamination) 是指病原体从一种食品（通常是生食）转移到另一种食品（通常是熟食）的过程。

### 生熟分开色标管理
在专业厨房或严谨的家庭管理中，工具必须分色：
- 🔴 **红色**：生肉类
- 🔵 **蓝色**：生海鲜
- 🟡 **黄色**：生禽类
- 🟢 **绿色**：蔬果/沙拉
- ⚪ **白色**：奶制品/烘焙
- 🟤 **棕色**：熟肉类

### 冰箱冷藏分区学问
冰箱内的垂直排列遵循“**最终烹饪温度从低到高**”的原则，由上至下排列：
1. **最上层**：即食食品、熟食、奶制品（无需加热）。
2. **中上层**：生蔬果。
3. **中下层**：生鱼肉、整块生肉。
4. **最底层**：生禽肉（如生鸡肉，因为其致病菌风险最高，滴漏的血水不能污染下方食物）。

## ⚙️ HACCP 体系基本原理映射

HACCP (危害分析与关键控制点) 是预防性的食品安全系统。对营养师而言，将其引入餐饮与家庭烹饪极具指导意义：

1. **危害分析 (Hazard Analysis)**：评估购买的生肉是否携带沙门氏菌。
2. **确定关键控制点 (CCP)**：对于生鸡肉，烹饪过程（加热）是消灭病菌的最后一步，因此“烹饪环节”是一个 CCP。
3. **确定关键限值 (Critical Limits)**：鸡肉的中心温度必须达到 74℃ 保持 15 秒以上。
4. **监控 (Monitoring)**：使用食品温度计插入鸡肉最厚部位测量。
5. **纠偏行动 (Corrective Action)**：如果测温只有 65℃，继续加热直到达标。

## 🥜 食物过敏原管理与交叉接触

食物过敏涉及免疫系统介导（IgE 等）的严重反应，微量暴露即可诱发过敏性休克 (Anaphylaxis)。

**全球核心过敏原体系（从“八大”向“九大及扩展”演进）**：
1. 牛乳 (Milk)
2. 蛋类 (Eggs)
3. 鱼类 (Fish)
4. 甲壳类 (Crustacean shellfish)
5. 坚果 (Tree nuts，如核桃、腰果、扁桃仁)
6. 花生 (Peanuts)
7. 小麦 (Wheat)
8. 大豆 (Soybeans)
9. **芝麻 (Sesame)**：**法定重大变更**——美国 FDA 根据《FASTER 法案》(FASTER Act) 自 **2023年1月1日起** 正式将芝麻确立为全美**第9大主要食品过敏原**，实施强制标签标示；中国 GB 7718 修订送审稿及欧盟 FIC 亦将芝麻、芹菜、芥末、亚硫酸盐等列入关键致敏物质清单。

**⚠️ 防护交叉接触 (Cross-contact)**：
过敏原的交叉接触与细菌交叉污染不同，**加热无法消除过敏原蛋白**。必须使用完全独立的器具、案板和油脂，彻底清洗表面，才能防范过敏反应。
