# 🏷️ 食品营养标签法规与避坑速查

> “食品标签是消费者与工业化食品之间唯一的信任契约，而营养师的责任是破解这份契约背后的真实代价。”
> 
> “‘0 反式脂肪’不等于健康，‘不添加糖’不代表没有糖，警惕包装正面的营销声称，真相永远在背面的配料表与营养成分表中。” —— RDN/CSSD 行业共识

## 📌 中国预包装食品标签法规核心标准

根据现行国家标准 GB 7718（预包装食品标签通则）与 GB 28050（预包装食品营养标签通则）：

### 强制标示的“1+4”至“1+6”升级演进
我国现行国标强制要求在预包装食品上标示“1+4”核心营养成分：
- **能量 (Energy)**
- **蛋白质 (Protein)**
- **脂肪 (Fat)**
- **碳水化合物 (Carbohydrate)**
- **钠 (Sodium)**

**📈 法规重大演进（GB 28050 最新修订版）**：
新版国标已正式确定将传统的“1+4”升级为**“1+6”**强制标示体系：
- 新增强制标示 **饱和脂肪（酸） (Saturated Fat)**：针对心血管健康防御；
- 新增强制标示 **糖 (Sugar)**：彻底击穿以往食品工业利用“高糖但只标总碳水”打掩护的盲区；
- 鼓励标示盐含量并增加对预包装食品正面营养信息（FOP, Front-of-Package）警示的指引。

### 营养素参考值百分比（%NRV）的精准计算
%NRV (Nutrient Reference Value) 是用于比较食品中某种营养素含量占每日推荐摄入量比例的指标。

$$
\%NRV = \frac{X}{NRV} \times 100\%
$$
*(其中 $X$ 为食品中某营养素的含量，NRV 为该营养素的参考值)*

**对营养师实操的意义**：
- 当一个食品的钠 %NRV 远高于能量 %NRV 时，提示该食品可能是“高钠陷阱”。
- %NRV 的基准是基于 2000 kcal 每日总能量消耗的成年人标准，对于减脂期客户或老年人，需根据其真实的能量需求进行按比例换算。

## 🧬 配料表“潜规则”与专业拆解

### 递减排列原则
国标规定：各种配料应按制造或加工食品时加入量的**递减顺序**一一排列；加入量不超过 2% 的配料可以不按递减顺序排列。
**实操价值**：配料表前三位决定了食物的本质。如果一款“全麦面包”配料表第一位是“小麦粉”而非“全麦粉”，说明其本质仍是精白面制品。

### 隐形糖与代糖：WHO 2023 甜味剂红线警示
1. **隐形糖代名词起底**：
   - **多糖/糊精类**：麦芽糊精 (Maltodextrin)
   - **糖浆类**：高果糖玉米糖浆 (HFCS)、葡萄糖浆、转化糖浆、枫糖浆
   - **浓缩果汁类**：浓缩苹果汁、浓缩葡萄汁（本质去除了纤维，主要成分即为游离果糖和葡萄糖）
   - **单/双糖提取物**：结晶果糖、海藻糖、无水葡萄糖
2. **⚠️ WHO (2023) 非糖甜味剂 (NNS) 官方指南警示**：
   - 世卫组织明确建议：**不应使用非糖甜味剂（如阿斯巴甜、三氯蔗糖、安赛蜜、甜菊糖等）作为控制体重或降低非传染性疾病风险的手段**。
   - 系统评价显示，非糖甜味剂对长期减脂并无实质净获益，反而可能维持大脑对高甜度风味的神经渴求，长期摄入甚至与 2 型糖尿病、心血管疾病风险轻度上升相关。
   - **营养师实操原则**：代糖饮料仅可作为从“高糖含糖饮料”向“水/淡茶”过渡阶段的短期替代，绝不能倡导“无糖代糖可无限量畅饮”，终极目标是重塑客户对天然低甜度食物的味觉敏锐度。

### 反式脂肪酸“0 标示”陷阱
国标规定：当食品中反式脂肪酸含量 **≤ 0.3g/100g** 时，可以标示为“0”。
**⚠️ 危险警示**：如果配料表中出现“氢化植物油”、“精炼植物油”、“植脂末”、“代可可脂”、“人造奶油”、“起酥油”等字眼，即使营养成分表反式脂肪标示为 0，长期大量食用仍可能累积心血管风险。

### 钠盐含量换算
营养成分表只标示“钠”(Sodium)，不标示“盐”(NaCl)。换算公式为：
$$
\text{盐 (mg)} = \text{钠 (mg)} \times 2.54
$$
**实操意义**：1g 盐 ≈ 400mg 钠。指导高血压患者时，需敏锐捕捉标签上的高钠数据。

## ⚡ 营养声称与功能声称红线

根据 GB 28050，食品包装上的声称必须符合严格的数值门槛：

| 营养声称 | 国标法定门槛数值 | 临床实操意义 |
| :--- | :--- | :--- |
| **高蛋白** | ≥ 12g / 100g (固体) 或 ≥ 6g / 100ml (液体) | 适用于增肌、术后恢复期选择优质蛋白源 |
| **低糖** | ≤ 5g / 100g (固体) 或 ≤ 5g / 100ml (液体) | 控糖人群的首选防线 |
| **无糖** | **≤ 0.5g** / 100g (固体) 或 ≤ 0.5g / 100ml (液体) | 并非绝对无糖，仍需关注碳水化合物总量 |
| **富含膳食纤维** | ≥ 6g / 100g (固体) 或 ≥ 3g / 100ml (液体) | 便秘、血糖控制客户的选品指标 |

## 🌐 国际营养标签系统关键差异对比

| 维度 | 中国 (GB 28050) | 美国 (FDA) | 欧盟 (EU FIC) |
| :--- | :--- | :--- | :--- |
| **标示基准** | 必须按 **每 100g/100ml**，可选择增加“每份” | 必须按 **每份 (Serving Size)**，且字体显著放大 | 必须按 **每 100g/100ml**，可选择增加“每份” |
| **碳水化合物** | 总碳水化合物（通常为减法计算所得） | **Total Carbohydrate**，需单列膳食纤维、总糖和添加糖 (Added Sugars) | **Carbohydrate**（特指可利用碳水，即 Net Carb），膳食纤维单列 |
| **纤维口径** | 包含在碳水中，纤维不扣除 | 净碳水 (Net Carb) 需营养师自行用 Total Carb 减去 Fiber 计算 | 标签上的碳水即为**净碳水**，不含纤维 |
| **添加糖** | 目前无需单列强制标示 | 必须强制单列标示 **Added Sugars** | 无需单列添加糖 |

**对营养师实操的意义**：解读进口食品标签时，必须先确认产地体系。美国食品的 Serving Size 陷阱极多（如将一瓶饮料标为 2.5 份，造成单份糖含量“看起来很低”的错觉）；欧洲食品计算生酮/低碳饮食时，直接看碳水数据即可，无需再减纤维。
