# 🏥 临床营养学 · 营养护理流程（NCP）与营养评估方法

> **核心临床与学术定位**
> 营养护理流程（Nutrition Care Process, NCP）是美国营养与饮食学会（Academy of Nutrition and Dietetics, AND）确立的一套标准化、系统化解决营养问题的临床思维框架。它是注册营养师（RD）及临床营养医师执行医学营养治疗（Medical Nutrition Therapy, MNT）的基石。在循证医学背景下，标准化的营养评估（Nutrition Assessment）是识别营养不良、指导干预及改善临床预后的首要环节（Grade A）。

## 📋 一、NCP 四步标准化流程

NCP 并非单一的操作，而是一个持续的、以患者为中心的闭环管理系统。

```text
+---------------------------------------------------+
|               以患者/客户为中心                   |

|  [1.营养评估] -----> [2.营养诊断]                 |
|       ^                   |                       |
|       |                   v                       |
|  [4.营养评价] <----- [3.营养干预]                 |

+---------------------------------------------------+
```

### 1. 营养评估（Nutrition Assessment）

营养评估是收集和解释数据的动态过程，以确定营养相关问题及其病因。临床上常采用 **ABCDE 评估法**。

#### (1) 主观与客观数据收集（ABCDE 法）
- **A (Anthropometry，人体测量)**：体重、身高、BMI、皮褶厚度、围度。
- **B (Biochemical，生化数据)**：血液、尿液生化指标等。
- **C (Clinical，临床评估)**：病史、体格检查（肌肉消耗、水肿、微量营养素缺乏体征）。
- **D (Dietary，膳食史)**：24小时回顾、食物频率问卷（FFQ）、膳食记录。
- **E (Environmental/Economic，环境与经济)**：进食能力、经济状况、社会支持、宗教信仰。

#### (2) 营养筛查工具的选择（Grade A）
不同人群需要使用经验证的专用筛查工具：

| 工具名称 | 全称 | 适用人群 | 核心要素 |
| :--- | :--- | :--- | :--- |
| **NRS-2002** | 营养风险筛查2002 | 住院患者 | 疾病严重程度 + 营养受损程度 + 年龄校正 |
| **MNA-SF** | 微型营养评估简表 | 65岁以上老年人 | 认知/抑郁、BMI、食欲、活动能力 |
| **MUST** | 营养不良通用筛查工具 | 社区/门诊患者 | BMI、体重下降、急性疾病影响 |
| **PG-SGA** | 患者主观全面评价 | 肿瘤患者 | 症状、功能、体检、体重、摄入 |

#### (3) 体成分评估技术（Grade B）
- **BIA（生物电阻抗分析）**：
  - *机制*：基于脂肪与无脂肪组织导电性差异（$$Z = \sqrt{R^2 + X_c^2}$$）。
  - *局限*：极易受水合状态影响，危重症或严重水肿患者慎用。
- **DEXA（双能X射线吸收法）**：
  - *地位*：体成分与骨密度评估的金标准。
  - *临床适用*：精确测量脂肪与瘦体重（LBM），特别适用于运动员与肌少症诊断。

#### (4) 生化指标的深度解读（Grade B）
临床上常用肝脏合成的内脏蛋白评估营养状态，但必须理解其半衰期及急相反应干扰：
- **前白蛋白（Prealbumin, PA）**：半衰期约 2 天，对早期营养不良及营养干预敏感。
- **视黄醇结合蛋白（RBP）**：半衰期 12 小时，极为灵敏，但受肾功能显著影响。
- **转铁蛋白（Transferrin, Tf）**：半衰期 8 天，受铁代谢影响。
- ⚠️ **安全红线**：在系统性炎症（如严重感染、创伤）时，C反应蛋白（CRP）升高，肝脏优先合成正性急性期蛋白，导致 PA、白蛋白（Alb）等负性急性期蛋白合成急剧下降。**此时低白蛋白血症反映的是严重炎症而非单纯营养不良**，单纯依靠生化指标会导致营养诊断错误！

### 2. 营养诊断（Nutrition Diagnosis）

营养诊断是连接评估与干预的桥梁，必须使用标准化的 **IDNT（International Dietetics and Nutrition Terminology）** 术语。

#### (1) 三大诊断类别
1. **摄入类（NI, Nutritional Intake）**：能量、营养素、液体的实际摄入与需求的差异（临床首选干预目标）。
2. **临床类（NC, Nutritional Clinical）**：与医学或身体状况相关的营养问题（如吞咽困难、代谢改变）。
3. **行为-环境类（NB, Nutritional Behavioral-Environmental）**：知识、信念、食物获取、食品安全等问题。

#### (2) PES 陈述规范（Grade A）
标准格式：**[P 问题] + related to / 与...有关 + [E 病因] + as evidenced by / 表现为 + [S 症状/体征]**。
*临床示例*：
> 能量摄入不足（NI-1.4）(P) *与* 化疗引起的恶心、食欲减退有关 (E) *表现为* 过去1个月体重意外下降 5% 且 24h 膳食回顾显示能量摄入仅为目标量的 60% (S)。

### 3. 营养干预（Nutrition Intervention）

#### (1) 干预策略分类
- **食品与营养素供给（ND）**：如肠内营养（EN）配方调整、补充膳食补充剂（ONS）。
- **营养教育（E）**：传授知识，如糖尿病饮食原则。
- **营养咨询（C）**：合作式的行为改变过程（如动机访谈）。
- **营养治疗协调（RC）**：与其他医疗团队（药师、言语治疗师）的转诊与协作。

#### (2) SMART 目标设定法
干预目标必须遵循 SMART 原则：**S**pecific（具体的）、**M**easurable（可测量的）、**A**ttainable（可达到的）、**R**elevant（相关的）、**T**ime-bound（有时限的）。

### 4. 营养监测与评价（Nutrition Monitoring and Evaluation）

干预效果的评估需要与基线数据对比，并调整策略。
- **监测频率**：根据病情严重程度而定（如 ICU 中重症患者需每日评估，社区慢病患者可每月评估）。
- **决策树模型**：
  - 目标已达成 ➡️ 终止干预或转入维持期。
  - 目标部分达成 ➡️ 分析障碍因素，调整干预方案。
  - 目标未达成 ➡️ 重新进行营养评估，修正营养诊断。

## 📊 二、常用临床营养评估量表详解

### 1. NRS-2002 营养风险筛查标准（ESPEN指南推荐）

总分 = 疾病严重程度得分 + 营养状态受损得分 + 年龄评分（≥70岁加1分）。**总分 ≥3 分提示存在营养风险，需制定营养支持计划**。

| 评分 | 营养状态受损（选最高分） | 疾病严重程度（选最高分） |
| :---: | :--- | :--- |
| **0分** | 正常营养状态 | 正常营养需求 |
| **1分** | 3个月内体重下降>5% 或 摄入量比正常减少25-50% | 慢性疾病急性发作，或轻度创伤（如髋骨折） |
| **2分** | 2个月内体重下降>5% 或 BMI 18.5-20.5 且一般情况差 或 摄入量减少50-75% | 腹部大手术、重度肺炎、血液系统恶性肿瘤 |
| **3分** | 1个月内体重下降>5% (3个月>15%) 或 BMI <18.5 且一般情况差 或 摄入量减少75-100% | 颅脑损伤、骨髓移植、APACHE II>10分的 ICU 患者 |

### 2. GLIM 全球营养不良共识标准（2018）

GLIM（Global Leadership Initiative on Malnutrition）是国际主要营养学会联合发布的营养不良诊断两步法。
**前提**：通过有效工具筛查提示存在营养风险。
**诊断标准**：必须至少符合 1 项表型标准 + 1 项病因标准（Grade A）。

**表型标准（Phenotypic Criteria）**：
1. 非自愿性体重下降（>5%/6个月，或 >10%/6个月以上）。
2. 低 BMI（亚洲人：<70岁 BMI < 18.5；≥70岁 BMI < 20）。
3. 肌肉量减少（通过 DEXA、BIA、CT 或小腿围测定）。

**病因标准（Etiologic Criteria）**：
1. 食物摄入减少或消化吸收不良。
2. 炎症负荷（急性疾病/创伤，或慢性疾病相关的严重炎症）。

## 🏃 三、营养评估在运动人群中的特殊考量

运动人群（特别是高水平运动员）的营养评估具有高度特殊性，不可机械套用临床通用标准。

### 1. 运动员体成分评估的特殊性
- **BMI 的局限性**：力量型运动员因去脂体重（Lean Body Mass, LBM）极高，其 BMI 常超过 25 甚至 30，若套用普通标准易被误判为“超重/肥胖”。在运动营养学中，必须结合体脂率（%BF）评估（Grade C）。
- **水合状态的干扰**：运动员频繁脱水与复水，使用 BIA 测量体成分时误差极大，建议在清晨、空腹、排空大小便后标准化测量。

### 2. LEA 与 REDs 的筛查（运动能量可用性不足）
女性运动员能量可用性低下（Low Energy Availability, LEA）可导致**运动相对能量缺乏症候群（RED-s）**，严重影响骨密度、内分泌代谢及免疫力。
- **评估指标**：能量可用性（EA） = (每日能量摄入量 - 运动消耗能量) / 瘦体重。临床界值：EA < 30 kcal/kg LBM/d 提示严重的 LEA。
- **LEAF-Q（女性运动员能量不足问卷）**：
  重点筛查三个维度：受伤史（尤其是应力性骨折）、胃肠道功能紊乱、月经周期紊乱。总分 ≥8 分提示存在 LEA 高风险，需进一步转诊治疗（Grade B）。
