# 🧬 临床营养 · 肠内营养(EN)与肠外营养(PN)实操

> 权威共识与核心声明：
> 1. "营养支持的首要黄金法则：If the gut works, use it.（只要肠道有功能，就使用肠道）。肠内营养不仅是提供底物，更是维护肠道黏膜屏障、预防肠道菌群易位诱发脓毒血症的关键。" —— *ASPEN / ESPEN 重症临床营养指南*
> 2. "肠外营养（PN）是挽救生命的技术，但其配制必须严格遵循渗透压与理化相容性规律；全合一（All-in-one）营养液是现代理想的输注载体。" 
> 3. "所有重度营养不良（如长期饥饿、神经性厌食）患者在启动营养支持前，必须将预防致死性的再喂养综合征（RFS）放在第一优先级，宁可起始能量不足（Underfeeding），绝不盲目达标。"

## 📌 临床营养支持决策树

营养干预应按照生理契合度进行阶梯式降级选择：
`膳食咨询 (Diet) → 口服营养补充 (ONS) → 肠内营养 (EN) → 肠内+肠外联合 (SPN) → 全肠外营养 (TPN)`

- **决策路径**：
  - 胃肠功能正常？ → 是 → 经胃途径（鼻胃管 NGT / PEG）。
  - 存在严重返流误吸风险（如昏迷、胃瘫）？ → 经空肠途径（鼻空肠管 NJT / PEJ）。
  - 肠道功能丧失（如短肠综合征、肠瘘、肠梗阻）？ → 启用 PN。

## 🧬 肠内营养（EN）配方与制剂学

### 1. 蛋白质存在形式（决定消化吸收能力）
- **整蛋白配方（Polymeric）**：适合胃肠功能正常的患者。分子量大，渗透压低（通常 ~300 mOsm/L），不易引发渗透性腹泻。价格便宜。
- **短肽 / 水解氨基酸配方（Oligomeric / Monomeric）**：无需胃液和胰酶消化，直接通过小肠绒毛吸收。用于急性胰腺炎、放射性肠炎。缺点：渗透压极高，必须用营养泵匀速泵入，口感极差。

### 2. 疾病特异性配方（Disease-Specific Formulas）
- **糖尿病配方**：低碳水化合物，增加**高单不饱和脂肪酸（MUFA）**比例，加入膳食纤维延缓胃排空，平稳餐后血糖。
- **肾衰配方**：极低磷、钾、钠；能量密度极高（高达 2.0 kcal/mL，以严格限制液体摄入量）。
- **慢阻肺（COPD/呼吸衰竭）配方**：**高脂低碳饮食**。
  - *机制（呼吸商 RQ）*：脂肪氧化代谢产生的 $CO_2$ 最少（RQ = 0.7），而碳水化合物最多（RQ = 1.0）。低碳水可显著减轻肺部排出二氧化碳的通气负荷。

## ⚡ 肠外营养（PN）的处方计算与配置

### 1. 输注途径的物理红线
- **周围静脉营养（PPN）**：通过手背/前臂静脉。**红线**：营养液最终渗透压必须 **< 900 mOsm/L**。若超过此界限，短时间内将引发不可逆的重度化学性静脉炎。配置以等渗脂肪乳为主，避免高浓度葡萄糖（只能用 <10% 的葡萄糖）。
- **中心静脉营养（CPN / TPN）**：通过锁骨下静脉、PICC 置管进入上腔静脉。由于血流量极大，可瞬间稀释高渗液体，允许输注高达 2000 mOsm/L 的高浓度全营养液。

### 2. 宏量营养素黄金比例
- **热氮比（Non-protein calories : Nitrogen ratio）**：
  计算公式为（非蛋白卡路里 ÷ 氮克数）。1克氮 = 6.25克蛋白质。
  - 一般中度应激：$150 : 1$。
  - 严重创伤/高分解代谢：$100 : 1$（投入更多蛋白底物用于修复）。
- **糖脂比（Carb : Lipid ratio）**：
  提供非蛋白热量时，通常采取 $50\% : 50\%$ 或 $60\% : 40\%$。长期单用大剂量葡萄糖会导致严重的高血糖、肝脏脂肪沉积（肝功能损害）。

## 🚨 致命并发症：再喂养综合征 (RFS)

再喂养综合征（Refeeding Syndrome）是长期饥饿或严重营养不良患者在重新接受大量营养（尤其是静脉输入大量葡萄糖）时引发的致死性代谢紊乱综合征。

### 1. 病理机制
```text
  长期饥饿状态 (消耗自身肌肉脂肪, 基础胰岛素极低)
       │
       ▼
  快速输入高浓度葡萄糖
       │
       ▼
  胰岛素骤然大量分泌 (Insulin Spike)
       │
       ▼
  合成代谢狂热启动，细胞疯狂摄取血液中的 钾(K+)、镁(Mg2+)、磷酸根(PO4 3-) 来合成 ATP 与细胞核酸
       │
       ▼
  致命性三低：严重低磷血症 (致死核心)、低钾、低镁
       │ (伴随水钠潴留)
       ▼
  呼吸肌无力 (脱机困难) → 心律失常 (室颤) → 急性心力衰竭 → 死亡
```

### 2. 实操干预与监测阶梯（阶梯式喂养）
- **高危人群确认**：BMI < 16、近期体重丢失 > 15%、超过 10 天未进食。
- **补充微量营养素**：在启动喂养前 30 分钟，必须大剂量静脉给予**维生素 B1（硫胺素，200-300mg）**，它是糖酵解通路的关键辅酶，预防韦尼克脑病。
- **喂养速度**：
  - 第 1-2 天：仅提供基础能量的 25%-50%（如 10 kcal/kg/d）。
  - 每日严密监控血钾、钙、磷、镁。一旦下降，立刻静脉补液纠正，切忌盲目提速。
  - 需 5-7 天后才逐步过渡到目标喂养量。
