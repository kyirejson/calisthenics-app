BLACK local wake-word recognition uses sherpa-onnx v1.13.8 (k2-fsa / Xiaomi).
Engine source: https://github.com/k2-fsa/sherpa-onnx/tree/v1.13.8

The native SDK also includes Microsoft ONNX Runtime (MIT License).
Its license is included in ONNX-RUNTIME-LICENSE.txt.
Upstream license: https://github.com/microsoft/onnxruntime/blob/v1.28.2/LICENSE

Keyword spotting model: pkufool, icefall-kws-zipformer-zh-en-3M-2025-12-20.
Author license: https://www.modelscope.cn/models/pkufool/icefall-kws-zipformer-zh-en-3M-2025-12-20
Apache License 2.0; upstream ONNX export/INT8 quantization, no local retraining.

Streaming Chinese ASR: csukuangfj, icefall-streaming-zipformer-small-ctc-zh-2025-04-01.
Author license: https://huggingface.co/csukuangfj/icefall-streaming-zipformer-small-ctc-zh-2025-04-01
Apache License 2.0; upstream ONNX INT8 model, no local retraining.

Speech activity: Silero VAD, Silero Team, MIT (SILERO-LICENSE.txt).
Model distribution is SHA-256 pinned in resources.json.
Source and license: https://github.com/snakers4/silero-vad

Local resampling: SpeexDSP 1.2.1, Xiph.org contributors,
BSD-3-Clause (SPEEX-DSP-LICENSE.txt).
Source: https://downloads.xiph.org/releases/speex/speexdsp-1.2.1.tar.gz
Only app-rendered audio is used as the playback reference; microphone audio stays in RAM.

Local echo cancellation: WebRTC AEC3, The WebRTC Project Authors,
BSD-3-Clause (WEBRTC-AEC3-LICENSE.txt). Standalone extraction by Enaium,
fixed revision 2cec2f52e26646f93bd2d5498bbabf59cba18da9:
https://github.com/Enaium/webrtc-aec3
Source archive hash is pinned in resources.json. No WebRTC network transport
or third-party real-time voice service is included. Android CPU feature
detection uses the Android NDK's BSD-licensed cpufeatures implementation.
Scoped denormal handling follows WebRTC's BSD-licensed
rtc_base/denormal_disabler.cc; the original thread FP mode is restored after DSP.
There is no prerecorded wake response. Every spoken response comes from the
configured Agent and the bundled local MeloTTS synthesis model (MIT,
TTS-LICENSE.txt and TTS-NOTICE.txt). There is no phone-system TTS fallback.

The bundled native AAR and model archives are fixed by SHA-256 in resources.json
and scripts/prepare-voice-resources.cjs. No audio recordings, passwords or accounts
are sent to these local models. After wake-up, transcribed text uses the existing
configured Agent API. Native microphone monitoring is explicitly user-controlled.
