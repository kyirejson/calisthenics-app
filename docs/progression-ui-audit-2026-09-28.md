# Uncover 进阶页重构（2026-09-28）

## 确认的业务规则

用户手动选择较高阶，表示对既有能力的自我确认，低阶视为已通过。这条规则保持不变；不要求补录低阶验收记录。

当前阶的专项验收次数另行展示，不能把设阶操作伪造为两次训练记录。六艺第十式为终式，其他路线使用既有最终形态；拓展动作不新增终式数量。

## 修改前发现

- 当前验收卡排在全部动作之后，当前阶不够突出；48 像素缩略图难以辨认姿态。
- 缺少原图放大入口；统一放大、裁切过的图片没有因此获得真实细节。
- 清单包含 23 条路线、223 个动作，221 个有本地图片，但这个数字不等于正确配图数量。
- 部分街头技巧、拓展动作的照片确实错配，甚至把训练表当作示范图。爆发动作首图大量使用共同起式，无法区分动作。
- 设阶值、验收次数没有充分防御非有限数值、重复记录、错误单位或未来记录；进阶保存缺少失败反馈。

## 先行设计

1. 深炭黑背景、荧光绿焦点；圆环只统计真实的既有终式状态，不使用模板示例百分比。
2. 四大类保持一行，小类横向选择；中文搜索保留，点击范围不小于 44 像素。
3. 终式目标卡置顶，当前阶使用更大的完整照片和验收入口。已通过的低阶默认收起，可展开；未来阶仍可查看指导和手动设阶。
4. 图片不裁切肢体，不加遮罩压暗动作。点击放大查看；原书同一动作的过程图分张浏览，不拼成一张。
5. 核对后选择更能体现动作的原书过程帧。明确错配的图片撤出渲染路径，缺少可靠配图时明示待补，不用别的动作充数。
6. 切换路线时只做短促的位移、透明度入场，无循环发光、无自动滚动抢手势；尊重系统减少动态效果设置。
7. 只修改本地；保留训练记录、用户设阶规则以及不相关的饮食开发内容，不上传、不发布。

动效采用 [React Native Animated](https://reactnative.dev/docs/animated) 的位移与透明度驱动；减少动态效果使用 [AccessibilityInfo](https://reactnative.dev/docs/accessibilityinfo) 和网页系统媒体设置。

## 实施结果

### 数据与交互

- 手动设为第 6 式时，第 1–5 式显示已通过，第 6 式为当前阶；训练历史和当前阶专项验收次数不因此增加。通过实际界面选择并返回进阶页，已验证此行为。
- 总圆环统计 23 条路线的终式解锁数，不统计 223 个目录条目。六艺选到第十式本身仍是当前阶，选择其后拓展阶数则承认第十式已通过；拓展动作不新增终式。
- 当前阶的记录验收仍使用既有的两次专项标准、至少间隔 24 小时的规则。重复 ID 不重复计数；无效设阶、未来时间、错误单位、未勾选的组、未完成的专项课不会制造验收成绩。空动作/空组与错误类型的勾选或条件确认值不会导致页面崩溃或通过验收。
- 进阶确认会重新核对当前数据，避免重复点击或过期弹窗覆盖新的手动设阶。取消不写入，保存失败不先改界面，也不改原记录；成功保存后刷新仍保留新阶数。
- 四大类在一行展示，小类横向浏览。当前阶突出、低阶可收起、拓展动作单独展开，搜索可跨分类定位。

### 图片与动效

- 当前阶照片从旧的小缩略图提升为 104 × 114 的完整显示区域；其他阶也有配图入口。图片不裁切、不压暗，点击后可放大、平移和恢复完整原图。
- 原书同一个动作的过程照片按图号分张浏览；图片区域按实际长宽比调整，而不是把两张拼成一张或留出固定的大块空白。
- 校正了靠墙倒立、桥类、半飞人/飞人俯卧撑、功夫打挺、后手翻/后空翻等封面帧，使封面更能体现动作，而不是统一使用起式。
- 收腿俯撑、完全后水平、高拉/上杠关键位置、悬垂直腿举腿的补充图，改用已核对的现有资料。补充姿态图只标为参考，不伪称原书完整教学过程。
- 图片选择统一到一个解析入口，训练、动作指导、进阶页和放大查看不再各自回退到不同的错误图片。删除了重复示范图引用，以及会重新引入章节装饰图的回退路径；原始文件和动作 ID 没有删除。
- 路线切换采用约 420 ms 的透明度与向上位移入场。安卓配置为原生动画驱动；网页帧采样验证了中间帧与单调变化。不会由查看原图、展开说明触发反复入场。
- 系统开启“减少动态效果”时立即显示，图片弹窗也不强制淡入。网页运行中切换该设置的行为，以及数据页原有动画，已回归验证。
