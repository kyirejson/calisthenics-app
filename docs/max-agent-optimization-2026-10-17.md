# MAX Agent 后续源码优化

日期：2026-10-17。接续 `max-reliability-and-token-audit-2026-10-17.md`。

用户要求：先补齐确定的优化点，暂不进行需要验证的手机场景，不发布。以下记录源码实现，不把旧基线的测试数字当作本轮结果。

## 1. 统一手机观察与 OCR

- 普通读屏、操作后观察共用 `PhoneController.observe`，统一返回真实画面、应用版本和观察/OCR 耗时。空树不会仅在其中一个入口触发 OCR。
- 同一请求、窗口、上下文、版本与边界的短期 OCR 结果可复用；页面事件发生变化后，旧识字坐标不可直接用于手势。
- Android 截图错误按系统错误码分别报告：频率限制、无障碍截图访问被拒绝、显示器/窗口无效、受保护内容和内部错误。只有明确的频率限制会在本地等候后重试一次，不将所有失败解释成“范围改变”或反复申请授权。
- 操作回执记录执行后观察的快照编号、版本等元数据；不再把整份屏幕树保存进流程重放账本。重放流程回执时重新观察当前画面，不展示旧画面冒充现在。
- 仍不能由此声称微信发送已经验收；系统受保护窗口不绕过，纯图标识别也没有被伪装成 OCR 已支持的能力。

## 2. 参数化流程、版本与真实证据

- 流程支持 `auto/accessibility/ocr`。自动模式优先真实控件；文字目标缺失时可用 OCR 整行文字定位点击/长按。填写仍要求真正可编辑的控件，不能把截图文字假装成编辑接口。
- 每个目标保留自己的快照来源，避免跨分页混用节点和快照。上下文条件也可以从本机 OCR 核对。
- 已执行步骤的最终观察可在版本未变化时复用；页面条件等待默认 8000 ms，模型可以通过 `timeoutMs` 调整。所有等待循环保留截止条件与取消检查。
- 保存必须关联同一用户请求中的成功原生回执、命令哈希、观察快照和真实应用版本。重试产生的不同 executionId 可以引用同一请求已经成功的步骤，不要求重复发送。
- 应用版本/安装更新时间变化、页面不符、目标重名等，会把流程标为待复核并回交模型。旧流程仍可读作参考，不禁用任何原有手机工具。
- 默认只返回流程摘要；可读取完整步骤，模型也能删除过时流程。
- 记录尝试、步骤执行成功/失败和耗时；不把 `sequence_executed` 当作用户目标成功。最后结果仍由模型根据实际页面核实。
- 流程修订使用独立标识，删除重建后，旧运行的迟到结果不能覆盖新流程；同一运行回执不会重复累计。
- 查询单个 App 版本时只读取筛选后结果的版本，不为所有安装应用逐个查询版本。

## 3. 外部播报期间的语音状态

- 明确区分可观察的导航播报、其他外部语音、播报尾音与播放元数据不可用。
- 增加周期性状态重读，补充漏失的播放回调；查询失败不让旧的播放状态永久屏蔽输入，迟到状态不覆盖更新状态。
- 暂停的是 KWS/ASR 输入接纳，AEC 与播放参考时钟继续运行；不让导航音频进入 VAD 的后续判停状态。
- 播报前已识别的用户话语予以保留，撤销旧语义探测，恢复后继续累计和判断。
- 暂停输入本身不会取消 MAX 的输出，不会清空对话，也不会把导航当成新的用户打断。
- 聊天状态与通知可以显示“导航播报中，结束后继续听”，同时保留真正的说话/生成状态。

**仍有明确边界：这不是第三方声音与用户人声的同时分离。导航与用户同时讲话时，仍可能暂不接纳用户输入；未被系统正确标注的播报仍可能混入。未新增声纹、屏幕/音频捕获授权或新云语音厂商。**

## 4. 按整次任务归因、减少重复上下文

- 原生语音片段提供稳定 taskId，使一次说话的语义判停与正式 Agent 请求归在同一任务；文字消息沿用原有请求编号。
- 记录实际 API usage、缓存 hit/miss、首个响应片段时间、模型耗时，以及工具总耗时、原生动作/观察/OCR/页面等待和流程命中情况。
- 生成成功、请求取消/失败、模型报告任务完成/受阻分别记录，不以收到 usage 作为回答成功证明。
- 保留最近 500 个模型请求与 2000 个任务事件。没有计数的请求仍是未知，窗口内的局部记录不冒充完整历史；重叠请求的耗时不能相加冒充实际等待时长。
- `read_agent_usage` 默认返回各榜前 10 条，可由模型继续分页读取，不一次把全部统计塞回上下文。
- 最新个人记忆与时间/执行状态位于对话之后，个人记忆更新不再提前打断稳定历史前缀；记忆内容完整提供，没有截断。
- 语义判停读取全部对话文字和工具状态摘要，不重复发送附件、控件树、工具参数。正式业务 Agent 的完整历史、附件和工具结果访问保持不变，没有添加关键词意图路由或工具轮次上限。
- 统计只保留数字与协议标识，不保存消息、参数、画面正文、录音或密钥。清空统计后，旧请求的迟到计数不重新写回。
