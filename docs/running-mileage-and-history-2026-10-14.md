# 跑步播报、数据统计与训练记录迁移

## 交付行为

- 跑步语音默认开启；保留用户已保存的关闭选择。跑步页提供小喇叭开关，跑步中切换不重启计时、GPS 或当前记录。
- 每跨过整数公里，语音汇报累计已测里程与不含暂停的累计用时；不展示播报文字，不再按五分钟播报。计步估算、定位缺失路段会在语音中注明，未测得距离不虚构公里数。
- 数据页保留原来的动作路线与成绩曲线，在下方新增跑步每日里程图、本周/本月总里程与累计里程碑。仅统计已保存的有效跑步记录；删除后重新派生，不保存独立的成就缓存。
- 训练日历、训练历史移到“我的”。主页面只渲染最新训练日；今天有记录则显示今天，否则显示最近一次。点击“查看全部”才打开完整列表，点击日历日期打开该日记录。
- 完整历史弹窗打开时，不重复挂载底下的最新记录。保留日期筛选、动作详情、单条删除及整日删除能力。
- “我的”的 DeepSeek 助手菜单入口已移除，全局聊天悬浮入口不变。
- 四个主标签使用同一个贴底导航组件。Android 继续使用现有宿主的系统栏安全区，不把按钮放到系统手势区域内。
- 训练完成后进入“我的”查看已保存记录；数据页的动作选择、指标和日期范围仍由应用层保存，往返页面不会复位。

## 本轮验证

- TypeScript 类型检查通过。
- Node 回归测试 485 项全部通过，无跳过。
- Android 跑步模块编译及 JVM 测试 11 项通过，包括 3 项新增公里播报格式/边界测试。使用独立 ASCII 构建快照，不使用正式签名、不覆盖正式 APK。
- 浏览器端 320×780、390×844、539×668、390×600、607×871 五种尺寸：贴底导航一致、历史最新/全部/日期列表、删除后的里程图及里程碑重算、默认语音及运行中开关、首公里只播一次且无文字提示，均通过。
- 训练历史卡片三种宽度、完整/部分重复训练、续练与整日删除、个人页四种尺寸回归通过。
- 动作路线/曲线的空数据、单点、动画、减少动态效果、单位区分、年份安全日历、触控与键盘查看、持久删除和重载回归通过。`UnifiedProgressCard.tsx` 无改动。
- 跑步地图、暂停时间排除、切页记录、断网记录、无定位计时、保存失败重试、重载恢复、室内手填距离及迁移后的历史回归通过。

## 验证边界与发布状态

浏览器 GPS、地图瓦片和语音验收使用独立测试上下文与合成输入，不写入用户浏览器记录，不代表真机定位、扬声器音质或设备中文 TTS 可用性已实测。原生验证为编译/JVM 测试，本轮没有运行新版正式 APK 的真机或签名升级验收。

网页开发预览已更新。当前改动尚未发布新 APK、推送 GitHub 或变更正式版本号；Android 的运行中喇叭开关需要包含新增原生接口的安装包，不能仅靠网页/JS 更新旧 APK。旧包缺少接口时会提示安装新版，不假装切换成功。
