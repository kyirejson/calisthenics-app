# 器械训练 v2：整周内容固定，低频合并、高频拆分

2026-10-02 更新：完成训练量、覆盖校验、配置隔离与代码清理。面向有经验、以均衡增肌为目标的训练者，不按单次时间或新手能力裁剪。此前 Mini–Ultra、13 类粗肌群补缺、跨周轮转和低频部位合并版已被替代；历史调研文件不代表当前实现。

## 设置与排课链路

|训练方式|可选每周次数|产品边界|
|---|---|---|
|传统五分化|5、6|保留胸 / 背 / 肩 / 腿 / 臂分日；六练把下肢辅助内容拆到第六日|
|PPL|3、4、5、6|低频合并推 / 拉 / 腿 A/B，高频拆分|
|上下肢|2、3、4、5、6|低频合并上 / 下肢 A/B，高频拆出辅助课|

这些下限是三种课表结构的产品边界，不是“低于某频率无法增肌”的生理结论。低频意味着单次训练量增加，不减少周内容，也不留到下一周补齐。

设置 → 选取同一份周动作与组数 → 按分化 / 次数合并或拆分 → 等效替换及器械检查 → 整周肌群、区域与功能审核 → 预览 / 保存 → 固定执行快照 → 记录实际完成。

每个训练周为计划起点开始的连续 7 天，与现有训练日历一致，不额外套用周一至周日。相同设置每周重复完整结构，课程身份按分化、次数和课次固定，不再靠跨周 A/B 轮转补缺口。训练日可以自选，但数量必须符合频率。

## 固定周动作银行

所有 11 种可选组合使用同一份周动作银行，总计 **156 工作组**，包含增肌主项、辅助项及控制练习，不是 156 组独立肌肉的“有效增肌组”。不同频率只改变分配；同一动作在低频合并时组数相加，不受旧版每动作最多四组的裁剪影响。

|内容单元|工作组|安排要点|
|---|---:|---|
|推 A|19|上斜推、水平推、推肩、侧平举、过顶三头、肩胛前伸|
|拉 A|25|下拉、上背划船、直臂下压、后束、二头、耸肩、外旋、伸腕|
|腿 A|31|哈克蹲、腿伸、腿弯、臀推、内收、直膝提踵、腹部屈曲、踝背屈|
|推 B|19|水平推、下胸方向夹胸、推肩、侧平举、三头下压、肩胛前伸|
|拉 B|29|下拉、上背划船、直臂下压、后束、二头、锤式弯举、耸肩、内旋、屈腕|
|腿 B|33|罗马尼亚硬拉、腿举、腿伸、腿弯、臀推、外展、屈膝提踵、腹斜肌旋转、抗旋转、抗伸展、躯干稳定|

实际动作、组数、次数与休息以 `src/data/equipmentDosePolicy.ts` 为统一周处方与剂量目标来源；`equipmentProgram.ts` 只负责分配。动作排序以复合动作优先，可按用户重点调整顺序；调整顺序不删组。预计用时由完整处方计算，仅为参考，不能反向限制课表。

## 审核不再只看粗标签

建立全部 112 个动作的执行元数据，明确主要参与、间接参与、稳定参与、动作功能与单侧执行。未知动作不再默认算核心。

每周同时审核：

- 28 个肌群账目：在主要肌群之外补上肩袖、肩胛控制、斜方、竖脊稳定、髋内收 / 外展、腓肠 / 比目鱼、胫前、腹斜 / 核心稳定、肱肌及腕屈 / 伸。
- 动作库的 28 个细分区域：如上胸 / 中胸 / 下胸，以及肩前束 / 中束 / 后束 / 肩袖 / 肩胛控制。
- 33 个功能目标：如水平推与上斜推、垂直拉与水平拉、髋铰链与屈膝、内 / 外旋、直膝 / 屈膝提踵、抗旋转 / 抗伸展。

区域不等于独立肌肉，各方向组数有交叉，不能相加当作总训练量。肩袖与肩胛、抗旋转与抗伸展归为控制练习；中立脊柱的罗马椅动作归为竖脊稳定参与，不冒充竖脊肌孤立动态增肌。预览显示“已安排”，而非声称用户已完成训练。

|主要肌群|每周最低直接组检查|
|---|---:|
|胸|14|
|背阔 / 上背|10 / 8|
|股四头 / 腘绳|12 / 10|
|臀 / 小腿|8 / 8|
|肩前 / 中 / 后束|4 / 8 / 6|
|二头 / 三头|8 / 8|

腹直肌 6 组、腹斜肌动态训练 4 组、上斜方 6 组；髋内收 / 外展、胫前、肱肌、腕屈 / 腕伸各 4 组。肩内 / 外旋、肩胛控制、抗旋转 / 抗伸展仍是独立的控制剂量，完整阈值见 `equipmentRegionTargets` 与 `equipmentFunctionTargets`。上述是产品起始配置，不是研究认证的最佳剂量。“达到检查阈值”只代表处方按预定义目标安排齐全，不代表一定获得足够刺激或增肌结果。

账目保留直接、间接、控制、稳定参与四类。间接参与的 0.5 折算仅用于近似展示；控制和稳定参与不折成增肌组，也不替代直接区域与功能检查。

## 替换、保存与执行一致

替换必须同时保留原动作的主参与肌群、细分区域、动作功能及控制 / 增肌目的，并具备必要器械。同属腿部、胸部或肩部不等于可替换：高脚杯蹲不能替代罗马尼亚硬拉，下胸夹胸不能用中胸飞鸟顶替，过顶三头不能用普通后踢代替。

器械缺失、非法替换、重复动作导致内容丢失、任一周区域 / 功能不足都阻止保存，不静默缩小处方。运行时只审核正在预览的 7 天，不重复计算 12 份相同课表；测试独立遍历未来 12 个计划周，并另查全年日历。默认所有 11 种组合均通过。没有等效动作时明确提示缺少器材，而非使用错误变式。

计划标识升级为 `equipment_training_v2`，新课程使用 `equipment_v2_分化_次数_课次`。旧器械档案迁移到合法频率并重启新版计划起点，不改写历史训练记录或其他专题阶数。旧课程 ID 不再作为当前课表入口。

新执行快照版本 **4**，固化动作顺序、组数、次数范围、休息、余力、单侧与重量口径。训练中加组不覆盖原处方。新版“完成”必须有当前版本与处方修订号，并记录每个动作足量有效勾选组；换动作或改课表后，旧课不能冒充新版已完成。今日状态与营养助手训练摘要使用同一校验，历史记录继续可读。

## 2026-10-02 审核修复

- 专题切换统一由存储层处理；分别持久化次数、计划起点、休息、时长以及器械分化、训练日、器材、替换等配置。返回原专题恢复原计划，不因街头健身的频率改变器械训练日。失败写入回滚；排队切换读取最新已保存档案。
- 剂量、区域目标与功能目标集中配置。运行时新增未配置区域 / 功能、非法组数、未知动作与失效目标均判定不完整，不能用 undefined / NaN 绕过保存限制。
- 训练参与表与动作库浏览侧重标签分离。直膝提踵同时直接训练腓肠和比目鱼；屈膝方向另设功能检查，不因直膝已有参与就删掉屈膝提踵。
- 腹斜肌增加绳索伐木的动态训练，逐侧记录；Pallof 抗旋转控制不能顶替腹斜肌增肌剂量。
- 显式替换与本课已有动作冲突时阻止保存，保留原默认行，不能静默改另一动作。缺器材的自动等效候选不能抢占别的默认 / 显式动作；编辑器可一键恢复默认替换配置。
- 清理退役课程与无效来源的替换设置；历史快照不清除。移除未使用的 issues 包装函数、重复重量口径判断、重复专题切换逻辑和重复 12 周运行时审核。
- 课程归属必须与当前分化 / 频率匹配。合并相同动作须同时匹配次数、休息、单侧与重量口径，不能把不同处方静默覆盖。
- 156 是当前银行的计算结果，不是优化目标、科学最优阈值或回归测试写死的常数。回归检查同一银行完整分配、剂量与方向缺失、元数据独立性及切换持久化。

## 研究与证据边界

[Pelland 等 2026 剂量反应元回归](https://pubmed.ncbi.nlm.nih.gov/41343037/)支持区分直接 / 间接参与及训练量递增但收益递减的方向，不能据此认证本 App 的 156 组或每个细分阈值。

[ACSM 2026 立场声明](https://pubmed.ncbi.nlm.nih.gov/41843416/)提供一般抗阻训练证据框架；不能把对较高周量的总体证据当成“所有辅助小肌群都应独立做 10 组”的规则。辅助剂量的具体 4–6 组是本产品处方选择，未获该声明单独验证。

[直膝与屈膝提踵原始试验](https://www.frontiersin.org/journals/physiology/articles/10.3389/fphys.2023.1272106/full)显示直膝训练比目鱼也有增肌；这支持修正参与分类，而不是认证本计划每个小腿组数。样本为未训练者，不能直接证明资深训练者的最佳剂量。

[2024 分化与全身训练系统综述](https://pubmed.ncbi.nlm.nih.gov/38595233/)发现周量匹配时分化与全身安排的增肌、力量差异未达显著；它不是对本 App 的 11 种方案或超大单课的直接验证。周内容一致也不意味着不同安排对每个人效果完全相同。
