# 安装与使用

[返回项目介绍](../README.md)

## 安卓安装

从[最新正式版](https://github.com/kyirejson/calisthenics-app/releases/latest)的 Assets 下载 APK，在 ARM64 安卓手机上打开安装。正式手机包只包含 `arm64-v8a`，不适用于 ARM32 手机或 x86 模拟器；独立包不依赖 Expo Go。目前没有正式分发的 iOS 安装包。

首次启动不强制填写档案，可以直接安排训练，再到“我的”补充个人信息。

## 更新与数据

在“我的”检查更新。更新时直接覆盖安装，保留本机记录，不要先卸载或清除数据。

应用支持 GitHub 安装包检查及 Expo 内容更新；原生模块或权限变更需要安装新的 APK。上传源码本身不等于已向手机发布更新。

档案、训练、饮食、跑步记录、照片及个人记忆主要保存在本机，不自动云同步，卸载可能丢失。应用目前没有业务 JSON 导入恢复功能。

## MAX 助手

使用前需自行配置有效的 DeepSeek API Key 并保证服务账户可用，模型调用由所配置服务计费。被助手读取的记忆、资料和附件会随请求发送到该模型服务；不会自动把整套知识资料放入每轮上下文。

语音唤醒、锁屏监听、蓝牙音频和后台运行受系统权限及厂商 ROM 影响；当前设备效果以实测为准。音乐和通用手机控制需相应的独立授权，可选 Shizuku 支持。系统授权、登录和受保护页面仍需本人处理。

## 跑步与资料

安卓跑步使用用户启动的定位前台服务；系统强制终止应用后恢复为暂停，不补算未记录距离。地图底图联网加载，断网不阻断 GPS；浏览器仅支持前台定位。

训练详情可阅读步骤、原文和配图，助手可只读检索已收录资料；APP 不提供整库浏览入口。训练和营养估算用于记录参考，资料与资源范围见[开发与功能说明](DEVELOPMENT.md)。

## 问题反馈

在[Issues](https://github.com/kyirejson/calisthenics-app/issues)说明版本、手机型号及复现步骤。反馈时隐去 API Key、个人档案、记忆、位置轨迹等私人信息。
