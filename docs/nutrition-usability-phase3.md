# 饮食易用性优化

> 本文保留饮食审核第二批的交付记录。后续训练饮食联动、目标历史、多轮问答与有限的 AI 输出校验已在 [第三批闭环说明](./nutrition-training-loop.md) 中实现；以下“不包含”描述的是本批次当时的范围。

2026-09-28，本地开发，不包含部署、APK 构建或代码上传。

## 已实现

- 饮食首页：已记录摄入与参考目标、各宏量营养素参考值、拍照/搜索入口、常用/最近餐、今日记录。推荐菜单及各餐食材做法默认折叠，菜单存在限制时保留提醒。
- 51 项可追溯参考食品与生活份量；新建、修改、删除个人包装食品，支持 kJ/kcal、每 100g/每份。食品快照独立于后续标签修改；未知纤维明确标识。
- 常用餐是独立快照。复用时先选餐次与份量，确认后新增 ID，不覆盖原记录；删除原记录不会删除收藏。
- 照片保存前后共用逐项编辑：删除、调份量、改名、用食品库替换、补漏识别食品/用油。改名不冒充营养重算，来源与估算区间保留。删除全部食物不能保存；可再补充本地食品。
- 新照片清空前一张的纠正备注；本地编辑后不会被同图再次识别覆盖。
- 换餐先显示候选、宏量差异与全日能量，只修改选中餐次。营养接近选项排前，较大差异需再次确认；不放宽过敏或饮食方式过滤。
- 记餐草稿固定打开时日期；计划餐与同餐次已有记录冲突时提示，避免把同一餐无意重复登记。

## 换餐比较规则

`getMealAlternatives` 以当前餐作比较：热量差不超过 10%，蛋白质差不超过 max(20%,5g)，碳水不超过 max(25%,10g)，脂肪不超过 max(30%,4g)，且全日能量方向不与所选增肌/减脂目标冲突。仅为 UI 比较规则，不是临床等效或达标保证。仍保留差异较大的选项供明确确认，不静默调整其他餐。

## 验证

- `npm run typecheck`
- `npm run test:nutrition`
- `npm run test:nutrition-service`
- `npm run test:domain` 与 `npm run test:updates`
- `scripts/test-nutrition-foods.cjs --source-archives <Foundation ZIP> <SR Legacy ZIP>` 可逐项核对官方下载数据。
- 可选浏览器冒烟：预览运行于 8081 后执行 `node scripts/smoke-nutrition-web.cjs`，需要可用 Playwright；也可由 `PLAYWRIGHT_PATH` 指向已有安装。脚本使用隔离浏览器与模拟识图响应，不读真实记餐或请求付费模型。

## 仍不包含

第一批审查中的生产鉴权、跨窗口数据一致性、健康风险事务保存、AI 过敏回答校验，以及第三批训练饮食自适应不在本轮范围内。本轮不能作为企业级正式上线验收。未新增条码/OCR、语音记餐、完整中餐数据库或生酮配餐；照片仍是估算，安卓/iOS 真机相机与键盘需另行验证。
