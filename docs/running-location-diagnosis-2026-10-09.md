# 跑步定位诊断与修复 · 2026-10-09

> 历史诊断记录，下面的“GPS 达标才能起跑”和“辅助定位仅限预览”已被替换。当前行为与验证范围见 [跑步可用性调整](running-usability-2026-10-09.md)。

## 已确认的软件缺陷

- 原定位预览在 App 离开前台时停止，返回前台只读取快照，没有恢复位置订阅。现保留用户的定位意图，在返回前台且仍处于待跑步状态时恢复；离开跑步页则取消意图，避免其他页面偷偷恢复预览。
- 未收到坐标时，按钮仍显示“点击启用定位”，没有区分未请求与已请求。现显示请求状态、等待时间；30 秒后明确“尚未收到位置坐标”，继续监听，不把等待期限当硬件错误。
- 开始按钮把普通等待抛成粘滞错误。现使用实时定位状态，坐标到达后自动更新；保留权限、请求和保存等真正失败。

## 原生诊断

每次快照读取当前精确位置权限、卫星定位提供者和系统定位开关；订阅记录监听状态、等待时间及请求失败类型。可用时读取 GNSS 卫星总数/参与定位数及其时效。未收到卫星状态不解释成“没有卫星”。坐标无效或超过 15 秒被拒收时给出对应诊断。

诊断仅在本机运行时显示，不保存坐标日志、上传日志或采集设备标识。采用系统 LocationManager/GnssStatus，无新增服务商或 Google Play 服务依赖。GNSS 状态注册失败不阻止 GPS 坐标订阅。

## 未改变的精度策略

地图仍可显示新鲜但精度不足的位置；开始记录仍要求估计误差不超过 35 米。15 秒为位置时效，不是手机必须完成搜星的时限。本次不伪造轨迹、不放大精度阈值掩盖定位失败。

## 验证与边界

- 新增 5 项测试执行实际状态分类与 React Host 控制流程，覆盖前后台恢复、离页取消、权限拒绝、请求异常、等待与成功。
- 396 项自动测试通过，严格类型检查通过。
- 隔离浏览器回归通过，包括 320/390/607 像素布局、无坐标等待、低精度回调、恢复、拒绝及原有跑步保存流程。
- 当前原生跑步源码在英文路径 QA 工作副本执行 :uncover-running:compileDebugKotlin，通过（Expo modules core 57.0.20、minSdk 24）。这不是新版完整发布 APK 或真机验收。
- 未连接用户手机，不能断言本次 OPPO 失败的唯一原因；已确认生命周期和反馈缺陷，不将室内环境当作已证实原因。
- 需要包含本次原生改动的新 APK 才能在手机读取诊断；v1.7.4 不包含此次修复。后续已按用户请求发布 v1.7.5/build 14，见 [发布核验](release-v1.7.5-2026-10-09.md)。

## 后续改进：辅助定位与地图分离（已发布 v1.7.6/build 15）

用户反馈 v1.7.5 显示卫星列表 45、参与定位 0，没有坐标。该列表大小来自 `GnssStatus.satelliteCount`，不是可用信号数量。无法仅凭这个状态证明手机故障或确认室内是唯一原因。已确认此前地图预览只订阅 GPS、没有系统辅助定位；无位置时默认北京地图也会造成误解。

- 预览同时请求系统 GPS、可用且开启的 NETWORK_PROVIDER，以及 Android 12+ 的系统 FUSED_PROVIDER；后者不是 Google Play 服务 SDK。单个提供者失败不阻止其他订阅，具体失败在快照中保留。离页、后台或开始跑步时移除所有预览监听。
- `mapPosition` 与 GPS `preview` 独立。辅助坐标只移动地图、不写入 GPS 日志；JS 里程计算也拒绝明确标记为网络、融合或缓存的点。起跑仍用新鲜 GPS 坐标，35 米不限制地图预览。
- 只展示有效、时效内的地图位置：辅助实时位置 60 秒、缓存位置 120 秒。缓存不启动定位、不冒充实时位置；新鲜可靠 GPS 优先，其次比较实时辅助位置和弱 GPS。位置失效移除定位标记，不补造坐标。
- 地图根据位置误差调整初始比例尺，大致位置用黄色标记并说明来源。未定位显示中性世界视图、可拖动浏览；删除原来的北京默认中心。
- 普通界面不再把卫星列表大小称为可用卫星，未完成定位显示直白状态。真正请求错误、系统开关、GPS 服务与辅助服务分别反馈。

验证：399 项自动测试、TypeScript 检查、隔离浏览器跑步回归通过。新增覆盖辅助位置不允许起跑/计里程、缓存过期、GPS 与系统开关区别、辅助请求错误、真实 Host 的网络位置转 GPS 起跑。Android 原生模块编译验证使用独立 QA 副本；不代表用户手机已收到坐标。手机必须安装包含这些原生改动的新 APK；v1.7.5 没有网络/融合预览功能。系统若所有提供者均不返回位置，App 仍不能凭空定位，也不能保证室内精确 GPS。

API 依据：[Android LocationManager](https://developer.android.com/reference/android/location/LocationManager)、[GnssStatus](https://developer.android.com/reference/android/location/GnssStatus)。

发布核验见 [v1.7.6 核验记录](release-v1.7.6-2026-10-09.md)，覆盖安装此版本后辅助定位才会在手机生效。
