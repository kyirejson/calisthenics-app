# 训练驾驶舱与今日训练衔接

后续调整：今日汇总已移入训练历史图表卡片，不再置顶；历史默认收起、互斥展开。最终界面与最新验证见 `training-history-chart-cards-2026-10-08.md`。

## 本次范围

按用户确认的动作卡 / 组轨迹 / 当前实际数量 / 环形休息设计落地，不改变训练计划、动作解锁或专项验收规则。采用现有动作配图，不将设计稿中的生成照片当作真实动作资料。

## 训练中

- `TrainingCockpit` 负责呈现；`TrainingScreen` 保留计划冻结、实际组校验、暂存、最终保存等业务逻辑。
- 动作卡可打开指导，通过动作菜单切换；切换不生成训练记录。
- 当前数量支持直接输入和加减，按“完成这一组”才记入；计划值不等于完成值。
- 完成后显示休息环、已完成组回执、下一组，可暂停、增加 30 秒或结束休息。
- 当前动作全做完后，结束休息或倒计时自然结束进入尚未完成的动作；不会自动完成任何组。
- 保持计时与手动休息为独立入口；保持倒计时结束也不自动保存组。
- 逐组编辑、加组、移除新增未完成组、添加动作及安全 / 整理入口收纳到记录面板。
- 修改已完成组会撤回该组完成状态，需重新确认，避免未经确认的编辑计入成绩。
- 器械训练保留重量计量口径、每侧约定、实际 RIR 与原计划快照；RIR 不自动填入。
- 训练时浮球隐藏，聊天在顶栏打开；其他页面继续使用浮球。
- 主操作固定在可滚动内容之外，采用键盘避让；呼吸式动画遵循系统减少动画设置。

## 完成与数据页

- 等待 `saveSession` 成功才进入数据页，传入稳定的 session ID；失败保持训练状态及已填数据，可重试。
- 训练历史内的日图表卡片展示实际完成组数、组数分布、总时长（含休息）与动作累计；逐组实际值、重量与余力按需展开。
- 默认全部收起，点击某一天展开；同一时间只展开一天。保存记录不自动展开，成功回执位于对应历史卡片内。
- 今日聚合沿用历史页的本地训练日期与有效记录规则；显式 trainingDate 优先，不使用 UTC 截日。
- 跨午夜结束仍按开始训练日期归档，保存回执与明细入口位于对应训练日，不伪装成今日统计。
- 同 ID 记录去重；不计未完成组、空记录、未来日期及旧跑步记录。不把秒 / 步 / 米混为次数。
- 原历史、进步曲线、日历与删除能力保留；刷新仍读取本机真实记录。
