# BLACK：回声不能授权插话

基线：v1.7.21。此次只修改声学输入准入、播放参考及对应回归，不更换 Agent、工具、ASR/TTS 模型或权限，不启用主人声纹，不发布 APK。

开发验收后，用户另行要求“更新”，据此按 v1.7.22 / Android versionCode 31 准备正式发布并同步源码。沿用既有正式签名与 ARM64 手机包；不重跑刚完成的功能回归，另行核验正式包、版本、签名和上传摘要。上文“不发布”描述开发阶段范围，正式发布不会补齐物理外放验收。

## 原有缺陷

`VoiceSpeechGate.confirm(text)` 把连续 VAD 人声和有效 ASR 字符作为暂停依据。残余助手回声同样是可转写的人声，因此会在语义判断前触发 `hearing → held → player.pause`，之后还可能进入新一轮 Agent 请求。

v1.7.21 的状态整理没有解决这个声源判断问题。回声能量变小的测试也不等于没有假插话。

## 单一声学准入链路

1. AEC3 持续接收完整麦克风及实际播放参考，仍使用其完整消除及残余抑制输出。不按文本相似度、唤醒词或整帧波形相关性封杀音频，不停止采集。
2. 从实际 suppressor 同步观察近端占优状态、近端/残余回声/噪声谱、线性估计可用性及饱和状态。JNI 同帧传递观察结果和延迟/ERLE 指标；不是只返回一个处理过的波形。
3. `VoiceAcousticEvidence` 输出 `NEAR_END / ECHO / UNKNOWN`。播放或回声尾声存在时，只有可靠参考和持续独立人声证据可以成为近端候选。无播放及尾声时，普通 VAD/ASR 仍正常工作。
4. `VoiceSpeechGate` 只消费声学来源及 VAD 概率，不再接收 ASR 字符串。近端语音达到候选/确认条件后，才发送 candidate/hearing。hearing 带播放参考 epoch；Service 拒绝路由变化后迟到的旧确认事件。
5. 同一准入结果控制 KWS、ASR、预卷和语义提交。ECHO/UNKNOWN 不进入识别器。播放保护期间，仅有 candidate 不得启动 ASR；须等 hearing 确认后回灌预卷，避免候选文字通过新模型请求旁路取消旧回答。没有播放保护时，正常用户输入仍可提前识别。完整 DSP 波形不被该准入规则改写。
6. 保留现有唯一会话总控和可恢复暂停；没有转写的误候选在片段结束时立即恢复，而非空等 30 秒。已有真实用户草稿和慢速续句仍保留。

初始保守条件：播放保护期间，需要 suppressor 的近端占优、可用线性估计、无饱和，以及近端谱高于回声和噪声估计；还须连续满足语音证据。它们不是说话人认证，也不是手机已实测过的精度保证。不能仅凭 ERLE 很高或识别出了字就授权。

## 不分叉第三方 DSP

`observe_echo.cmake` 校验固定上游 echo_remover.cc 的 SHA-256，在构建目录产生仅增加只读观察点的编译单元，并从编译列表移除原单元。vendor 源文件、谱、增益及算法均不修改，也不链接第二份 EchoRemover。上游不匹配时停止构建，不能静默丢失观察点。观察 sink 为处理线程作用域，合成/重采样实例不能覆盖识别实例的证据。

## 播放和采集参考的保护

- 写入队列不等于硬件已播出。回退时间估计可供 AEC 使用，但不能作为允许打断的可靠参考。
- 保护覆盖写入前瞻、静音间隙、暂停/取消后已经播放声音的尾声，不靠当前帧参考是否非零判断“助手已停止发声”。
- 生产者保留最多 3 秒参考，以覆盖录音队列最大约 1.024 秒的积压；消费者按采集时间读取，不能被较新的播放写入提前删掉对应参考。
- 输入/输出路由改变或硬件时钟大幅校正会使旧证据失效、重建 AEC 并重新收集证据。短暂不可靠时继续播放、保留手动停止入口，不把不可靠帧当新用户。
- `BLACK-VoiceInput` 只记录限频的来源、时钟可靠性、证据块数及 AEC 指标，不记录语音内容或用户录音。

新增 Android 用例通过公开合成语音和采集输入端口执行真实 AEC/VAD/KWS/ASR：

- 纯助手回声包含 BLACK、多句连续播放、20/80/320 ms 延迟、噪声、削波、压缩，以及中途增益/延迟变化；均未 hold、输出用户转写、提交语义请求或唤醒自身。

语义返回值在测试中注入，不能冒充真实联网模型质量。固定声学回放不等于真实扬声器、房间及麦克风测试。

单架构 Gradle 调用的测试 APK 路径以当前任务输出清单为准；历史 outputs/apk 目录可能留着旧包。安装前检查 APK 内的新用例/实现类及设备安装包摘要，不能只检查 Kotlin 编译文件。

## 交付边界

用户手机尚未安装此次原生改动。没有 Find X8 Pro / ColorOS 16.0.10 的物理外放数据，不能承诺所有音量、距离和环境下零误判。

这次排除的是本机助手回声，不验证真人身份。其他真人及电视里的声音不能因此被声称为“主人声音”。不确定时优先保持回答；极端路由或时钟不可靠时，自动插话可能暂时不可用，手动停止仍可用。不得以关闭麦克风或取消全部插话功能冒充全双工修复。
