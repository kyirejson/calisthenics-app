# 用户自带 API Key：申请与使用指南

更新：2026-10-03。

## 先看这三点

- 可以选择“智谱：一个 Key 聊天＋搜索”，或保留“DeepSeek＋Tavily”。同一个智谱 Key 分别调用聊天与搜索服务，不等于免费或只发一次请求。基础本机课表查询、明确记餐与训练调整不需要模型 Key。
- 开发版已接入“个人助手 → 齿轮 → 连接设置”。手机默认个人密钥直连，浏览器本地开发默认网关、可手动切为直连。不要把 Key 填进聊天、个人记忆、歌单输入框或普通用户档案。新增系统安全存储需要安装新原生包，旧安装包不会自动获得此功能。
- 不再要求使用 Render。服务可自行部署；公开知识库也不意味着问答模型、搜索服务或用户数据需要公开。

## 1. 创建 DeepSeek Key（联网问答）

1. 打开 [DeepSeek 官方 API 平台](https://platform.deepseek.com/)，注册或登录自己的账号。
2. 进入 [API Keys](https://platform.deepseek.com/api_keys)，创建专用于 Uncover 的密钥，建议命名 `Uncover-personal`。
3. 复制密钥，暂存于自己的密码管理器；不要发送给开发者、公开群或助手对话。
4. 在平台查看余额与消费情况。API 消耗与网页聊天是不同使用入口；具体计费以 [官方模型与价格](https://api-docs.deepseek.com/quick_start/pricing) 为准。
5. 打开个人助手右上角齿轮，选“个人密钥直连”和 DeepSeek，在密钥栏粘贴。点击“保存并验证连接”将保存并发送一次最小文字测试，可能产生费用；“仅保存，不验证”不会请求模型。保存成功不等于连接通过。自托管方式则由服务所有者设置 `DEEPSEEK_API_KEY`，不是把密钥放进公开源码。

官方连接地址为 `https://api.deepseek.com`；当前官方文档使用 `deepseek-flash` 等模型名。模型列表会变化，App 应提供可验证的配置，不固化价格或承诺永久免费。申请入口与接口说明见 [官方首次调用指南](https://api-docs.deepseek.com/)。

## 2. 创建 Tavily Key（可选，联网搜索）

1. 打开 [Tavily 官方平台](https://app.tavily.com/)，注册或登录。
2. 在 Dashboard 的 API Keys 区查看或创建密钥；新增密钥可点击该区的 `+`。
3. 为 Uncover 单独命名，按平台能力设置月度用量限制。
4. 在同一连接设置的 Tavily 栏填写并保存，不能填进 DeepSeek 密钥栏。自托管服务使用 `TAVILY_API_KEY`。
5. 没配置时应显示“搜索未配置”，不能把模型记忆伪装成最新联网结果。普通问答不必因此禁用。

步骤依据 [Tavily 官方密钥指南](https://help.tavily.com/articles/9170796666-how-can-i-create-an-api-key)。额度、套餐与限速以登录后的官方平台为准。

## 3. 常见问题

### 国产方案：智谱聊天＋搜索

1. 打开 [智谱开放平台](https://bigmodel.cn/)，注册／登录自己的账户，在账户 API Keys 页面创建专用 API Key。
2. 按平台要求开通模型与搜索服务，查看额度和账单。普通 API Key 与其他产品的订阅额度不能自行视为等价。
3. 在 App 选择“个人密钥直连 → 智谱聊天与搜索”，粘贴完整密钥，点击“保存并验证连接”。这个按钮只测试文字模型，不自动测试搜索。需要时再点“测试智谱搜索”，该请求也可能计费。
4. App 固定调用官方聊天和搜索地址，搜索只发送检索词；模型接收本次问题及相关档案／历史。未把密钥转交开发者服务器，也不再要求填写 Tavily Key。
5. 当前白名单是 `glm-4.7`、`glm-4.5-air` 文字模型。图片接口会在本机明确提示暂不支持，而不是用文字测试假装图片能力已验证。

接口依据：[智谱对话补全](https://docs.bigmodel.cn/api-reference/%E6%A8%A1%E5%9E%8B-api/%E5%AF%B9%E8%AF%9D%E8%A1%A5%E5%85%A8)、[智谱网络搜索](https://docs.bigmodel.cn/api-reference/%E5%B7%A5%E5%85%B7-api/%E7%BD%91%E7%BB%9C%E6%90%9C%E7%B4%A2)。后者返回来源链接和摘要；App 仍过滤无效来源，不信任模型编造的链接。真实账户开通、费用和手机网络连通性以实际测试为准。

| 情况 | 处理 |
| --- | --- |
| 密钥无效／鉴权失败 | 核对服务商与复制内容，去官方平台确认该密钥未被撤销；不要把完整错误请求或 Key 发到群里。 |
| 余额或额度不足 | 查看服务商账单和限额，不要反复重试付费请求。 |
| 能聊天但不能搜索 | DeepSeek 方案检查 Tavily 配置；智谱方案核对搜索服务开通与额度，聊天测试不证明搜索可用。 |
| 网络连接失败 | 检查网络与配置端点；本地课表和确定性记餐仍应可用。 |
| Key 曾发到聊天／截图／仓库 | 立即在官方平台撤销，再新建专用 Key；仅删除聊天消息不等于撤销。 |

## 4. 开发版已实现与验收边界

- Android/iOS：个人 Key 使用系统安全存储；不写 AsyncStorage、SQLite 对话、知识档案、导出 JSON、错误日志或 `EXPO_PUBLIC_*`。提供遮罩、替换、删除与官方申请链接。
- Web：默认只保存在当前会话内存。需要长期配置时，由用户控制的可信服务保存；不得假称浏览器普通存储与手机安全存储等价。
- 默认提供“保存并验证连接”，按钮上方明确一次文字请求与可能费用；同时保留“仅保存”和独立重试测试。仅输入 Key、启动、健康检查和返回设置都不自动付费。文字测试不证明图片能力。
- 点官方平台入口前，仅保存一天有效的返回连接设置标记；没有保存尚未提交的密钥。普通后台返回保留本页，进程回收后的重新启动也会恢复设置页；操作完成或关闭后移除标记。真实手机跨 App 返回仍需验收。
- 同一 Harness 校验、营养计算、确认模式、实际成功回执继续生效，不因“自己的 Key”而让模型直接写数据库。
- 公开知识库采用可再分发内容白名单。版权书全文、原书图片、私密对话、个人档案及授权唤醒模型不得随源码公开；《囚徒健身》私密全文索引目前也不在公开白名单中。
- 直连共用已有 Harness、专家路由、来源校验、搜菜和配方计算，不需要 Render，也不把个人密钥转发给开发者网关。检索服务仅接收用户检索词，但检索词自身仍可能含个人信息。
- 手机系统存储、真实密钥网络连通性、浏览器服务商跨域兼容均需实际验证；本轮使用隔离假接口回归，没有消耗真实用户额度。直连没有读取服务端私人原书索引，只使用内置来源摘要及实际联网结果。
