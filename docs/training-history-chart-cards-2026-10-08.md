# 训练历史图表卡片

## 最终界面

- 图表仅放在训练历史列表项内；数据页顶部保留进步曲线，不再置顶“今日训练”汇总。
- 历史默认全部收起，列表只保留日期和简短组数 / 训练次数。
- 点击某个训练日展开图表；同一时间只展开一个训练日，打开另一天自动关闭前一天。再次点击可全部收起。
- 保存训练、重新打开数据页及刷新不自动展开历史。
- 图表呈现该日完成组数分布、真实用时（含休息）、训练次数及各动作累计。
- 原来常驻的逐组文字摘要列表删除；每组值 / 重量 / 余力通过动作行按需展开，点击日历日期可查看单次记录和删除入口。
- 历史图表底部的“已记录／查看明细”及曲线底部的摘要、前后箭头全部删除，不留下空白底栏。曲线仍可点选、横向滑动或用网页左右方向键查看真实观测点。
- 切换训练日或收起时清除旧明细展开状态。

## 统计与存储

`dayTraining.ts` 复用历史页有效记录与本地训练日期规则。环形图只比较实际完成组数；不将次数、秒、步、米或重量混合成图表比例，不当作目标完成率或肌肉训练强度。

相同 ID 的暂存版本不会重复计入。同日重复训练累加；删除任一记录同步重算。不同单位、每侧约定和重量口径分别保留。历史日期按对应训练日汇总，不误读取今天；未知用时明确标注，旧跑步记录继续可从明细查看，不进入力量组数图。

未修改或清除用户真实训练记录。旧 `TodayTrainingSummary` 组件及今日专用聚合路径已被统一的日历史实现替代。
