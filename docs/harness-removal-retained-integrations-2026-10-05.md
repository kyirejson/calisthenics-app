# 旧 Harness 移除与集成保留

按用户要求，仅保留个人助手原有的 DeepSeek API Key 和网易云音乐集成，不开发新 Harness。

- `src/integrations`：DeepSeek 密钥安全存储、会话验证、纯网络客户端；网易云授权、MCP 客户端、资源匹配、安卓播放桥。
- 设置入口：我的 → DeepSeek 聊天 → 右上角设置。连接验证成功后收起密钥输入区，音乐按绑定状态展示。
- 已删除：聊天界面、浮动入口、系统提示词、专家路由、工具调度、操作权限与兜底回复、长期记忆、compact、助手课表覆盖、语音录制与唤醒、系统助手快捷指令、旧服务端与失效测试／文档。
- 饮食拍照／标签／条码作为独立业务保留在 `src/nutrition/capture`，不是旧 Harness 的兼容层。
- 训练、饮食、跑步记录和手动操作保留；旧助手存储迁移只删除其 Markdown、归档和索引，不删除 DeepSeek 密钥、网易云会话或业务记录。
- 旧原生桥导出名 `UncoverCopilot` 保留用于现有安装包兼容，其源码现在只含两个网易云调用；不保留助手实现。
- 独立 `music-mcp` 服务及其私有凭证未清除。旧助手服务器环境文件已移到项目外恢复目录，不再属于运行配置。

移除的实现与旧原生构建产物备份在 `D:/001号仓库/removed-personal-assistant-20261005`，不打包、不发布。

这些改动不等于发布新 APK。网易云真机自动播放仍需手机验收；浏览器模拟联调只验证服务绑定与 API 设置。
