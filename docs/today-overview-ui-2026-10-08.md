# 今日训练 · 任务谱设计模板

按用户最新确认的任务谱设计图调整本地界面，取代上一版合并动作列表。保留真实训练处方、动作图片和已有记录，不使用设计图中的示例次数或合成人物配图。

## 页面布局

- 顶部大字「今日」与日期，右侧排列 Uncover 和紧凑训练／饮食切换，替代原有整行大切换栏。
- 七日日期条在前，日程、阶段小标签与全年日历入口在后；选择日期直接切换主界面的课程、动作、组数与注意事项，不再弹出日程详情卡。打开动作指导后返回仍保留所选日期。
- 课程区采用无外框的大标题、细竖线和折线装饰，不绘制假进度或假趋势。保留真实周期和完整课程身份，训练完成后只改变状态标签，不抹掉课程名。
- 每项动作是一张独立任务卡，左侧编号连线，第一张橄榄色渐变，后续为石墨色；右侧使用原动作配图，无详情箭头，整张卡仍可点击查看动作指导。
- 每一个空心方格代表计划中的一组，数量、值及单位全部取自实时处方。单侧与左右合计口径保持显示；方格不绑定完成记录，不制造已完成进度。
- 常见屏幕采用 42px「今日」、32px 课程标题、18px 动作名；较短或窄屏幕使用 38px、28px、17px。卡片高度利用剩余空间调整，长名称、更多组数或更多动作允许自然换行和滚动，不裁切内容。
- 添加动作、移除自加动作、倒立条件、重置和全年日历继续使用原有业务逻辑。
- 浏览其他日期不产生训练记录，也不提供今日的加／删／重置操作；底部显示「回到今日训练」，返回当日后才可开始／再练一次。休息日和有氧日展示各自安排，不借用今天的力量课程。
- 开始／再练一次按钮在滚动区域之外，20px 按钮文字、14px 圆角；今日页的描边聊天入口与按钮同高同基线。此页隐藏浮动重复入口，离开今日页后原全局悬浮球恢复。
- 今日页采用设计图中的底部平面导航，其他页保持原有导航外观；倒立条件与重置整合为一条次级工具栏。
- 上一版合并列表、缩略图位置、字号分支和无效样式已清理；饮食与器械专题的主体未重做。

## 屏幕边界

三动作常规日经 360×800、390×844、607×871、739×871 浏览器验证可完整同屏显示。320×780、较短屏幕、较长课程、自加动作或放大字体仍允许自然滚动，不隐藏动作或压小文字，开始按钮保持可见。

## 验证

- TypeScript 检查与 355 项自动测试通过；新增选中日期的只读课程解析、独立自加动作／训练状态、休息／有氧安排和跨日行为测试。
- `smoke-today-overview.cjs`：上述尺寸、实际字号、每组方格数量与值、十组高容量课程的换行和无裁切、长列表加／删动作、短屏幕、休息日、减肥控重、训练／饮食切换、主界面日期切换与指导返回、聊天打开关闭与页面切换恢复、固定开始按钮和聊天同基线。
- `smoke-training-ui.cjs`：阶段草稿选择、取消、应用和真实训练记录。
- `smoke-repeat-training.cjs`、`smoke-training-cockpit.cjs`：完整／部分训练保存、重复训练累计、失败重试及数据页衔接。
- `smoke-fitness-flows.cjs`：全年日历、未来日程、原图加载和训练动作切换。

所有浏览器验证使用隔离存储和测试档案，不接触用户当前标签页的数据。本次未构建或发布新的安卓安装包；原生安全区和字体放大效果仍需真机验收。
