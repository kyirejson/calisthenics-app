# Uncover 今日与训练界面升级验收

本轮按用户确认的设计图实施，仅本地修改；未提交、推送、上传、打包或发布更新。训练方案、营养算法及既有用户数据不作重置。按 work-transparently 技能清理被替代的实现、无用导入和样式残留，并完成隔离验证。

## 界面与比例

- 今日的训练、饮食、跑步三个横滑分页面，以及训练中页面，统一采用进阶页的深色背景、荧光绿主操作、圆角卡片和图标体系。
- 共用最大内容宽度 440、左右内距 16、页面标题 22；摘要圆环 64，主要操作不少于 44。桌面居中显示手机画布，不拉宽手机卡片。
- 训练首页将课程、周进度、动作入口、日历和日常编辑分层；倒立条件的长说明放入详情。未恢复重复的今日能量及健康与康复首页卡片。
- 饮食突出已记录摄入和参考目标，拍照、搜索与营养助手各有入口；保留菜谱折叠、逐项纠正、确认记餐和历史快照，不把计划能量冒充实际摄入。
- 跑步使用同一套内嵌/全屏记录组件；距离、配速和地图由真实定位数据产生。保存失败仍保留本次数据，可重试。
- 训练中扩大休息计时器，组号、实际次数和勾选列对齐；保留加组、实际完成量、退出确认和仅保存勾选组的规则。
- 相关动作详情、热身、全年日历及饮食弹层同步适配；全年日历每月翻页，未来日期能显示对应课程。月统计包含恢复课，标签改为“有安排”，不误称力量训练天数。

## 原图适配

- 六艺 60 个基础阶的封面，按对应原始资料逐张检查主体位置与原始尺寸，在 `exerciseFraming.ts` 保存展示用裁切区域。
- 卡片按主体比例适配高度，等比缩放；不为了填满卡片裁去脚尖、手掌、头部或关键支撑点。纵向引体/倒立与横向俯卧撑/桥不使用同一个固定图框。
- 本轮没有改写或重新压缩原始图片。原文过程图逐张展示；原文、动作详情主图与放大查看保留完整原图。放大入口仍支持分张、缩放及恢复完整显示。
- 基础阶原片宽度为 628 像素，裁切无法创造不存在的高清细节。其他既有不可靠或未收录配图仍保留待补提示，不拿其他动作充数。
- 颈部手阻、单腿提踵沿用既有补充演示；它们不属于书籍原图，原文详情保留来源说明。本轮不新生成示范图。

## 动效与记录

- 切换进阶路线、切换训练动作使用短促的透明度/向上位移；安卓配置原生动画驱动，网页验证中间帧与单调变化。
- 地图定位光环复用动画值，不随每次坐标变化重新启动；减少动态效果设置下不播放循环光环或强制入场。
- 手动选择较高阶仍承认较低阶已通过；不会因此制造专项验收或训练记录。
- 仅点开训练、切换动作或未勾选退出均不新增历史；勾选后记录实际正数，取消全部勾选撤回空草稿，秒数不混入次数。

```powershell
npm run typecheck
node --test scripts/test-progression-redesign.cjs
node scripts/smoke-fitness-ui.cjs
node scripts/smoke-fitness-flows.cjs
```
