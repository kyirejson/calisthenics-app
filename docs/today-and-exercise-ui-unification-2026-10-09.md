# 今日训练与动作详情 UI 统一

## 范围

以现有徒手健身今日页为视觉基准，同步减肥控重与器械训练；完成所有共用动作详情页的设计落地。没有修改训练计划引擎、真实训练记录口径、进阶门槛、模型或 API 配置。

## 今日页

- 三种训练目标共用 `todayTrainingStyles` 和 `TodayTrainingTask`：日期栏、紧凑计划入口、课程标题、编号动作清单、处方组数格和底部开始按钮。
- 器械页移除独立大摘要卡、周进度条和旧动作行。保留真实预计时间、次数范围、每侧要求、负重计量、组间休息、器材不足提示与计划设置。
- 减肥控重周安排改为课程下的轻量说明，保留实际力量/有氧安排与年龄相关注意事项。
- 不截断动作或组数。普通三动作课适配一屏；多动作、高容量课和短屏可以滚动，开始按钮保持固定。

## 动作详情

- 徒手和器械共用 `MovementDetail` 阅读画布、固定底部操作、下划线页签、编号要点与折叠纠错。
- 徒手保留原始配图、训练标准、来源、风险提示、设为当前阶和专项训练行为；原文阅读不重复显示封面与概览指标。
- 器械保留独立现代指导、生成示范标识、评级说明和证据链接，不借用书籍原文，也没有新增不存在的单动作开练能力。
- 切换阅读页签回到阅读起点。折叠组件明确暴露展开状态；同一纠错或标准组内一次只展开一项。

## 同时完成的遗留 UI 修正

- 删除饮食页“计算与知识依据”及其无消费者的展示专用模块；实际营养计算与 App 知识库未移除。
- 今日页移除自己额外渲染的静态聊天球，复用全局可拖动入口。鼠标和触摸拖动支持边界限制与吸边；拖动不会误打开聊天。
- 网页聊天切换取消退出动画，避免快速关闭/键盘重新打开时被尚未退出的焦点层截获；原生聊天保留原有滑入动画。
