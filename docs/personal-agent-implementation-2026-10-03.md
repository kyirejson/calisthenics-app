智谱实现依据 [官方聊天 API](https://docs.bigmodel.cn/api-reference/%E6%A8%A1%E5%9E%8B-api/%E5%AF%B9%E8%AF%9D%E8%A1%A5%E5%85%A8)、[官方搜索 API](https://docs.bigmodel.cn/api-reference/%E5%B7%A5%E5%85%B7-api/%E7%BD%91%E7%BB%9C%E6%90%9C%E7%B4%A2)。固定域名、超时、响应大小、来源 URL 过滤、自动纠错和本机确认规则共用，不另铺一套营养计算或业务执行器。

第二轮验收：TypeScript 通过；全量 **583／583** 通过；320／390／1280px 的全局入口、拖拽／吸附／重启／关怀折叠，以及设置页恢复、仅保存、保存验证、两种供应商搜索、密钥不泄露测试通过。现有助手 320／390／650／1280px、Harness 320／390px 回归通过。Android JS／Hermes 导出 1781 模块通过，**不是 APK、原生编译或真机验收**。网络测试使用隔离假接口，没有消耗真实账户额度。

尚需继续：私人原书本机导入／检索（不得未经许可公开打包 1368 条摘录）、可关闭的本地通知、完整口述训练记录澄清与录入、全内联相机、授权唤醒资源、原生与真机验收、依赖告警兼容修复。音乐仍仅请求系统打开，不保证网易云身份、歌单加载或自动起播。本轮未安装新依赖、修改锁文件或执行强制审计修复。

## 已实现的 App 与 Harness 链路

| 阶段 | 本地实现 | 验收边界 |

| P0 | 全局 AI 入口、页面场景上下文、事务卡片与较长咨询文本、明确选择的份量参照 | 回复不恢复 50 字限制；份量按钮是粗略选择，不默认套用“每碗”重量。 |
| P1 | 换动作、改组数、课程减载、多日顺延、显式两日交换与整组撤销；网易云歌单绑定／打开 | 默认确认／完全访问共用本机验证。音乐只保证向系统发送打开请求，不保证自动播放。 |

## 数据闭环

入口 → 当前页面与实际档案／课表／日志快照 → 明确本地意图或一个联网专家 → 草案 → 权限／基线／参数再校验 → 原子写入 → 成功回执 → 本地事件刷新。

- 训练修改存储为按专题、计划指纹、日期限定的覆盖层。原模板和真实历史不改写，不额外持久化第二份主训练档案。
- 计划频率、器材、重点肌群等设置变化使旧覆盖层失效；已实际执行的课程、历史日期不可由助手重写。
- 连续换动作保留原动作槽位的自定义组数。减载后周训练量审计如实展示差异，不再称原增肌剂量已达标。
- 调期区分顺延与交换，不复制课程；顺延以日期归属循环映射保存，原日变休息、课程逐次后推。老配对记录仍兼容。撤销恢复整个关联组，任何关联日已训练或进入历史则拒绝单边撤销；重叠调整需先撤销。
- 手动追加动作随课程调期投影到新日期，底层原日期数据保留；读投影与写归属分别处理，适用于双日交换和非对称多日顺延。在新日期追加、删除和重置会反查所属日期。重启与撤销不丢失追加动作。训练覆盖层提交期间阻止并发改档案／训练数据，避免追加写到旧日期；完成后恢复写入。
- 存储失败不生成成功回执；音乐打开已经发生但回执失败时明确提示已发出请求、不要重复。
- 音乐目前是**候选协议接入**：`canOpenURL` 仅检测系统处理器，不验证处理器身份、网易云版本、歌单加载或播放成功。没有手机实测或跨版本保证；检查失败才选择官方网页，调用打开失败则报告错误。原规划里的“100% 落地／自动起播”不作为当前能力或验收结论。
- 两周体重上下文采用两个互不重叠的七个日历日窗口，每日最多一个有效实测值。无数据不填充；比较包含有效天数与均重，接近不等于诊断平台期。
- 餐次分类自愿。“没吃”是用户明确状态，未记录不等于没吃；不要求补齐早餐／午餐／加餐／晚餐。

## 原生系统入口配置与实际限制

### Android

源目录：`modules/uncover-copilot/android`；Expo 自动链接本地模块。Porcupine Android 依赖为 `4.0.2`。

在取得相应许可后，将**面向 Android、匹配该 SDK 的**文件放入：

```
modules/uncover-copilot/android/src/main/assets/uncover-wake.ppn
modules/uncover-copilot/android/src/main/assets/porcupine_params_zh.pv
```

上述文件已忽略提交。需要用户当前启动会话的 Picovoice AccessKey，不得把它作为 DeepSeek Key；没有模型时 UI 明确显示不可用。SDK 配置依据 [Porcupine Android 官方文档](https://picovoice.ai/docs/quick-start/porcupine-android/)。模型许可与是否可向公众随包分发须独立确认。

用户在 App 前台授予麦克风与悬浮窗权限后手动开启，显示常驻通知。检测后释放麦克风，点通知／悬浮入口打开助手；一分钟后自动结束等待。进程死亡不自动重启、没有开机监听、不存原始音频。长按说话前也先停止唤醒监听，避免两路争用麦克风。

Android 对后台启动麦克风服务有实际限制，不能承诺“任何位置、永久监听”。依据 [Android 前台服务限制](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start)。OPPO 后台策略、权限、通知、锁屏与返回输入框均需真机验收。

### iOS

`plugins/with-personal-agent.cjs` 将唯一 Swift Intent 源加入应用目标，Expo 原生模块读取应用内短时待处理命令。Siri 打开应用并填入问题；**不会自动发送或执行修改**。待处理内容读取后清除，过期五分钟丢弃。

基于 [Apple App Intents](https://developer.apple.com/documentation/appintents)，不是私自常驻后台麦克风监听。需要 macOS/Xcode 构建与 iPhone 的 Siri／快捷指令验收。原生模块新增必须安装新包，不能用 OTA 内容更新替代。

## 不使用 Render 与用户自带密钥

手机默认个人密钥直连固定官方端点；本地 Web 开发默认已有网关，可以在连接设置手动切换。没有静默回退旧 Render 地址，不再配置 Render。未关闭或删除既有公网服务，因为该操作不是本次请求范围。

独立“连接设置”、DeepSeek/Tavily 或智谱个人密钥、按服务商隔离的模型白名单、保存并验证／仅保存／独立测试和删除已在开发版接通。手机使用 `expo-secure-store`，Web 仅内存；不写聊天、普通档案、导出备份，不上传个人密钥到开发者网关。模型仅有配置与测试结果之分，不把健康检查中的密钥存在当成真实连通证据。申请步骤见 [用户密钥指南](user-api-key-guide-2026-10-03.md)。

`personalTransport.mjs` 使用同一 Harness 与返回校验；联网检索、菜品参考配方和相机提示词分别抽为可移植模块，服务端通过导出入口复用，未维护两套业务规则。个人直连没有服务端原书索引，原书检索明确不可用。真实模型／搜索／图片能力仍需用户自有账户和手机验收；新增 SecureStore 与系统入口需要新原生安装包，本轮未发布。

公开知识库前需内容来源、许可、版本和可再分发白名单；知识内容与私人记忆必须拆分。没有公开《囚徒健身》全文索引、授权唤醒模型或用户数据。
