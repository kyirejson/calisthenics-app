# 一、 胸部肌群 (Chest)

胸大肌分为**锁骨头（上胸）**、**胸肋头（中胸）**与**腹肋头（下胸）**。纤维起止点各异，需依肌纤维走行方向匹配器械运动平面。

### 1.1 S 级（必选黄金项 · 极高刺激疲劳比与拉长位张力）

| 动作中文名称 | 英文名称 | 细分解剖靶向 | 核心器械类型 | 阻力曲线与力学生物学机理 | 动作执行要点与 2-1-2-1 节奏 | 避伤红线与禁忌错误 |
|:---|:---|:---|:---|:---|:---|:---|
| **30° 上斜哑铃卧推** | Incline Dumbbell Bench Press (30°) | 胸大肌锁骨头 (上胸) | 自由重量 / 30°可调凳 | 自由轨迹允许双手微旋聚拢；底端离心拉伸使锁骨头深度进入肌小节降支，激发拉长位肌肥大 (SMH)。 | 慢速 2~3 秒下落至胸肌拉满；手肘内收 45°~60°；推起时爆发 1 秒，顶峰意念双肘聚拢。 | 严禁长凳调至 45° 以上（导致前束代偿）；严禁 90° 直角大开肘卧推（撕裂前关节囊）。 |
| **30° 上斜史密斯卧推** | Incline Smith Machine Press | 胸大肌锁骨头 (上胸) | 史密斯机 (固定导轨) | 极高神经稳定性，消除平衡肌力消耗，允许受训者在最深拉长位安全冲击力竭 (0~1 RIR)。 | 躺于凳上，使杠铃下落轨迹对准锁骨下方 2~3cm；2-1-2-1 控速，底端微停 0.5 秒。 | 严禁手腕极度后仰压迫正中神经；杠铃严禁直接砸击胸骨。 |
| **坐姿水平对敛推胸机** | Seated Converging Chest Press | 胸大肌胸肋头 (中胸) | 固定凸轮/杠杆推胸机 | 轨迹向内收敛 (Converging)，消除自由重量在顶峰的力矩衰减；胸背贴紧靠背，消除下背借力，SFR 极高。 | 座椅调至手把对准乳头连线高度；推起时全力收缩中胸，回放时肩胛骨收紧贴合靠背。 | 严禁耸肩推起（斜方肌代偿）；冲重量时腰椎严禁离开靠背过度反弓。 |
| **蝴蝶机夹胸 (Pec Deck)** | Machine Flye / Pec Deck | 胸大肌中胸/全胸横向内收 | 凸轮单关节夹胸机 | 纯单关节水平内收；凸轮全程匹配力量曲线，底端离心深拉伸安全可控，顶端等长挤压充分。 | 肘部微屈并锁死角度；大臂带动前臂向胸前画大圆弧聚拢；顶峰挤压 1 秒，缓慢 3 秒离心放回。 | 严禁通过伸展手臂或手腕弯曲拉扯配重；拉长位不要超过肩关节解剖舒适活动度。 |
| **平板哑铃卧推** | Flat Dumbbell Bench Press | 胸大肌胸肋头 (中胸) | 自由重量 / 平板凳 | 大行程深拉伸；左右侧独立做功，对于单侧肌力与围度失衡具有无可替代的纠偏作用。 | 哑铃下放至胸外侧深位，小臂垂直地面；推起时哑铃向内汇聚至锁骨正上方。 | 哑铃顶点严禁猛烈碰撞；严禁起桥让臀部悬空。 |
| **胸肌双杠臂屈伸** | Chest Dips (Weighted/Assisted) | 胸大肌腹肋头 (下胸) | 双杠 / 配重腰带 | 下胸第一王牌动作。自重结合外加负荷，极深离心下沉为下胸与胸小肌提供巨大的机械张力。 | 躯干主动前倾 30°；手肘向两侧自然展开 45°~60°；下沉至大臂平行于地面即可，推起至手肘微屈。 | 严禁躯干完全直立（直立会变成三头肌做功）；严禁无控制骤降到底（容易拉伤胸大肌胸骨端附着点）。 |
| **绳索高位向斜下夹胸** | High-to-Low Cable Flye | 胸大肌腹肋头 (下胸边缘) | 双滑轮绳索 (Cable) | 滑轮置于最高处，拉力方向向斜下方 45° 放射，**100% 对齐下胸肌纤维走向**，消除自由重量在底端的死点。 | 站立核心微屈前倾；双手握把向肚脐前方斜下方挤压靠拢，顶峰交叉手腕挤压 1.5 秒。 | 严禁依靠背部前后摆动甩动重量；肩胛骨在动作初始保持下沉固定。 |

### 1.2 A 级（优秀进阶项 · 强力补充与单侧精雕）

| 动作中文名称 | 英文名称 | 细分解剖靶向 | 核心器械类型 | 阻力曲线与力学生物学机理 | 动作执行要点与 2-1-2-1 节奏 | 避伤红线与禁忌错误 |
|:---|:---|:---|:---|:---|:---|:---|

| **平板史密斯卧推** | Flat Smith Machine Bench Press | 胸大肌胸肋头 | 史密斯机 | 轨道固定，减少肩袖稳定肌群疲劳，专注胸大肌募集。 | 调整长凳使横杠平齐中胸；手掌虚握或全握，匀速 2-1-2-1 推举。 | 严禁出架后手腕过度向后弯折承重。 |

| **水平中位绳索夹胸** | Middle Cable Flye | 胸大肌中胸中缝 | 双滑轮绳索 | 纯水平剪切拉力；支持在顶峰手腕交叉，实现胸肌全幅度缩短。 | 滑轮平齐胸部高度；向前画大弧度环抱大树姿态；控制回放。 | 身体过度后仰变成划船反向借力。 |
| **下斜哑铃卧推** | Decline Dumbbell Press | 胸大肌腹肋头 (下胸) | 哑铃 / 下斜凳 (15°~30°) | 肩关节最舒适力学角度，推力上限极高，下胸边缘轮廓雕刻优秀。 | 双脚勾紧挡板；下放哑铃至下胸两旁，垂直爆发推起。 | 起身时不要直接扔哑铃，先放置大腿再起身。 |
| **坐姿器械双杠推胸** | Seated Dip Machine | 胸大肌腹肋头 | 坐姿插销推胸机 | 双杠臂屈伸的安全平替，大体重与肩关节不稳定者友好。 | 坐稳贴紧靠背，双手握把垂直向下推到底部，收缩下胸。 | 耸肩耸肘；座椅高度太低导致手腕压迫过大。 |
| **30° 上斜杠铃卧推** | Incline Barbell Bench Press | 胸大肌锁骨头 | 杠铃 / 30°架 | 大重量刺激上胸；神经负荷强。 | 杠铃降至锁骨正下方 1~2cm；注意推起轨迹微向后上方弧线。 | 握距过宽造成手腕肩袖过载。 |
| **手柄加深俯卧撑** | Deficit Pushup on Handles | 全胸拉长位强化 | 俯卧撑把手 / 踏板 | 手下垫高 15cm，使胸部打破地面阻碍深陷下沉，获得极强拉长位肌肥大 (SMH)。 | 慢速 3 秒下沉到底部拉伸位停顿 1 秒，爆发推起。 | 塌腰骨盆前倾。 |

# 二、 肩部肌群 (Shoulders)

三角肌分为**前束 (Anterior)**、**中束 (Lateral)** 与 **后束 (Posterior)**。前束在推胸中已承受大量复合负荷，因此现代训练重心在**中束球形肩雕刻**与**后束后链平衡**。

### 2.1 S 级（必选黄金项）

| 动作中文名称 | 英文名称 | 细分解剖靶向 | 核心器械类型 | 阻力曲线与力学生物学机理 | 动作执行要点与 2-1-2-1 节奏 | 避伤红线与禁忌错误 |
|:---|:---|:---|:---|:---|:---|:---|
| **肩胛面绳索侧平举** | Cable Lateral Raise in Scaption | 三角肌中束 (球形肩核心) | 单滑轮绳索 | 滑轮置于膝关节高度，彻底消除哑铃底端力矩臂为零的缺陷；在**肩胛骨平面（Scaption，身体前倾 15°~30°）**向侧前方拉起，杜绝冈上肌撞击。 | 身体微前倾，沿侧前方 30° 画大圆弧抬起至大臂水平；手腕不要高于手肘；顶峰停顿 1 秒。 | 严禁耸肩用上斜方肌代偿；严禁在身体正侧冠状面直板侧平举。 |
| **哑铃肩胛面侧平举** | Dumbbell Scaption Raise | 三角肌中束 | 自由重量 / 哑铃 | 中束自由重量王牌。手肘沿肩胛面微内收 20°~30°，手心微朝下（倾斜大拇指水平向内），中束激活最大。 | 肘微屈锁死，抬至与肩平齐即可；慢速下放至大腿两侧前侧。 | 严禁身体前后借力摇晃；哑铃抬起严禁超过肩水平线（超过 90° 均为斜方肌做功）。 |
| **蝴蝶机反向飞鸟** | Reverse Pec Deck Flye | 三角肌后束 / 菱形肌 | 固定反向飞鸟机 | 坐姿胸板支撑消除脊柱代偿；大臂在水平外展面后拉，后束做功极其孤立纯粹。 | 座椅调至手把与肩平齐；双手微旋手背朝外；向两侧后方展开挤压后束，顶峰停顿 1 秒。 | 严禁耸肩把压力转嫁到斜方肌上束；严禁前臂拉拽弯曲手肘。 |
| **坐姿对敛式推肩机** | Seated Converging Shoulder Press | 三角肌前束 / 中束上部 | 杠杆/凸轮推肩机 | 轨迹自动向内收敛；相比自由杠铃推举消除了腰椎过度反弓后仰，极适合冲击超负荷高张力。 | 坐稳靠紧椅背；手把下落至耳垂高度即可，推起至手肘微屈不停留。 | 严禁下落过深压迫肩关节囊；座椅太高导致推起时耸肩。 |
| **绳索面拉 (附外旋)** | Cable Face Pull with External Rotation | 三角肌后束 / 冈下肌 / 小圆肌 | 绳索 / 双头麻绳 | 现代肩袖健康与体态救星。水平后拉同时加入手腕向后外旋动作，全面强化后肩与肩袖稳定肌群。 | 滑轮平齐面部高度；双手抓绳向后拉至双耳两侧，大臂展开成“投降”姿态，肘部保持高位。 | 严禁下拉至脖子或胸口；手肘不要下坠。 |

### 2.3 B 级（针对性补充项）

| 动作中文名称 | 英文名称 | 细分解剖靶向 | 核心器械类型 | 阻力曲线与力学生物学机理 | 动作执行要点与 2-1-2-1 节奏 | 避伤红线与禁忌错误 |
|:---|:---|:---|:---|:---|:---|:---|

# 五、 腹部与核心 (Abs & Core)

# 七、 2026 动作评级与底层数据字典规范 (Data Schema)

为了让上述 6 大肌群的所有 B 级以上黄金动作能**无缝接入 Uncover App 的代码架构与进阶页**，设计如下标准数据模型：

```typescript
// 规范化器械动作接口定义
export type MuscleGroupCategory = 'chest' | 'shoulders' | 'back' | 'legs' | 'abs' | 'arms';
export type EvidenceRating = 'S' | 'A' | 'B';
export type EquipmentType = 'dumbbell' | 'barbell' | 'cable' | 'machine' | 'smith' | 'bodyweight_load';

export interface ResistanceExercise {
  id: string;                      // 唯一结构化ID，如 'gym_chest_incline_dumbbell_press'
  name: string;                    // 标准中文名，如 '30° 上斜哑铃卧推'
  nameEn: string;                  // 英文名，如 'Incline Dumbbell Bench Press'
  category: MuscleGroupCategory;   // 部位分类
  subTarget: string;               // 细分靶向，如 '胸大肌锁骨头 (上胸)'
  synergists: string[];            // 协同肌群，如 ['三角肌前束', '肱三头肌']
  rating: EvidenceRating;          // 2026 循证评级: S | A | B
  equipment: EquipmentType;        // 核心器械类型
  
  // 2026 生物力学属性
  biomechanics: {
    lengthenedFocus: boolean;      // 是否为拉长位肌肥大 (SMH) 高收益动作
    resistanceCurveProfile: string;// 阻力曲线类型，如 '全行程恒定剪切' | '底端拉伸极强' | '顶峰内收聚焦'
    cue: string;                   // 2026 动作核心心法，如 '推起顶点意念在双肘内聚而非碰撞哑铃'
  };
  
  // 规范化实操指导
  coaching: {
    setup: string;                 // 器材与起始校准
    execution: string;             // 动作轨迹与发力
    tempo: '2-1-2-1' | '3-1-1-1';  // 离心-停顿-向心-挤压 节奏
    safetyRedlines: string[];      // 避伤禁忌与红线
  };
  
  // 超负荷递进模型
  progression: {
    model: 'double_progression';   // 双重渐进超负荷模型
    defaultRepRange: [number, number]; // 如 [8, 12]
    stepIncrementKg: number;       // 达标后推荐加重幅度，如 2.5kg
  };
}
```
