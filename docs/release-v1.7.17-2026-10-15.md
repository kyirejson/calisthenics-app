# v1.7.17 · 专属主人声纹与连续语音交互

Android versionCode 26，应用 ID 和正式签名不变。覆盖安装完整 APK 后，在服务设置中登记主人声音，再开启 BLACK 语音唤醒；旧开发版声纹需重新登记。不要卸载或清除数据。

## 更新内容

- 新增本地 CAM++ 主人声纹：三段 BLACK 开头的不同朗读及一次独立 BLACK 回读，分别建立长语音、短片段和唤醒模板，回读通过才加密保存。
- 每个新音频包独立验证主人身份，不沿用前一包权限，不把旧主人人声拼入新尾音。旁人插话不进入 Agent，也不清除前面已验证的本人文字。
- 慢速表达按同一草稿累计；只读模型判定回应、等待或忽略。未完成的半句话不提前执行工具；等待和故障可恢复，裸 BLACK 省去额外判停调用，由原模型答应一次。
- 修复登记取消/删除竞态、朗读中途换段、长回答结束后续听窗口立即过期，以及迟到回调影响新请求的问题。
- 修复系统 TTS 的音色选择、请求拒绝/合成失败恢复；播放候选暂停可恢复，播放故障不伪装成用户打断，完整回答文字保留。
- 文字与语音共用会话和现有 Agent，保留原模型、全部授权工具及简洁表达提示。执行回执作为独立工具消息，不混入助手口语。
- 增加公开网页搜索与正文分页读取；Android 逐跳检查公开地址，不携带账户 Cookie。不需要新增豆包/火山账号或付费语音服务。

## 验证与边界

- TypeScript、546 项 Node 回归、55 项原生 JVM 策略测试通过。
- 整个 App Android Kotlin 编译，以及自有 Android 15 模拟器 11 项 instrumentation 通过，覆盖真实 KWS/VAD/CAM++、加密存储、系统 TTS 接口、AudioTrack 播放/暂停/取消和公开网页请求。
- 正式发布门禁检查 APK 版本、既有签名、四 ABI、本地模型哈希、原有跑步诊断和嵌入式 JS；测试类与测试录音不得进入正式 APK。
- 登记音频与声纹不上传；仅加密特征保存在本机不参与备份的目录。公开源码不包含个人声纹、聊天、训练记录、附件或密钥。
- 没有连接用户的 ColorOS 真机。极短通用口令、多人重叠、远场及原厂中文 TTS 仍需手机验收；声纹不是抗重放/抗克隆的身份认证，不承诺豆包同等准确率或端到端时延。

详细设计见 [主人验证与连续轮次](voice-owner-turns-2026-10-15.md)，功能对照见 [豆包对照审核](voice-doubao-review-2026-10-15.md)。原生模块更新必须安装 APK，网页刷新和 OTA 不能替代。
