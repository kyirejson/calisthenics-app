# 训练记录、续练、跑步和资料可见性修复

日期：2026-10-09。本文件保留第一批修复完成时的审计快照，下述“未发布”和功能缺口仅描述当时状态；当前跑步补齐及发布验收请参阅 [跑步行为与验证](running-behaviors-2026-10-09.md) 和 [v1.7.8 发布核验](release-v1.7.8-2026-10-09.md)。

## 根因与处理

| 问题 | 已查明原因 | 本批处理 |
| --- | --- | --- |
| 整日删除后仍有记录 | 历史页日期带前导零，存储日期不带；精确字符串比较漏删 | 统一日期比较；提供“删除当日全部记录”；同时清理当日临时动作和旧迁移备份 |
| 删除后再次出现 | 删除和未结束的异步暂存可能交错 | 串行写入；成功删除的 ID 拒绝迟到保存；失败删除不损坏原记录 |
| 退出后重做已完成动作 | 再次进入按新课初始化，没有恢复课程记录 | 保存课程快照和已完成组；续练沿用同一 ID、原开始时间和累计训练时长；优先打开尚未完成的动作 |
| 今日页看不到已完成组 | 清单只显示计划量 | 今日清单展示已完成数量和组状态；徒手与器械课程使用同一显示方式 |
| 重复勾选 | “完成这一组”与编辑列表中的勾选都能确认完成 | 保留主操作确认；编辑数量不取消完成状态；已完成组可撤销，未完成组不再提供重复勾选 |
| 手机原文、原图缺失 | EAS 上传排除了原文和原图，安装预处理因此生成空映射 | 修复上传规则；正式构建验证原文及全部映射对应文件，缺失则阻止发布 |
| 我的页面冗余入口 | 多个功能入口重复或不符合本次要求 | 删除训练日历、饮食与营养、震动设置、导出备份入口及其页面绑定 |
| 知识库显示 | 我的页面可直接打开全库 | 移除 App 全库浏览入口；保留助手内部检索及动作详情的原文配图 |

同一天“再练一次”是独立训练记录，数据页按实际完成组累计；“继续今日训练”更新同一条未结束课程，不重复累计。主动结束部分训练后，它成为已结束记录，而不是继续中的课程。

删除单次记录只删除那一次；删除整日记录会删除当天所有力量、跑步记录和临时添加动作。其他日期及用户选择的训练阶段保留。图表、日历、今日完成状态均从剩余记录重新计算，不保留被删除记录的统计。此处是应用层删除，不承诺取证级擦除，也无法追回用户此前另存的文件或系统备份。

## 跑步交互与对标边界

增加自由跑、3/5/10 公里和 20/30 分钟目标、可取消三秒倒计时、全屏专注、大字距离/用时/平均及当前配速、防误触长按解锁、亮屏控制、暂停继续、保存成功总结和历史公里分段。目标达到后不会擅自结束跑步。

分段用有效轨迹跨过每公里的位置插值计算时间，不生成虚构轨迹。暂停不计时、不连接暂停前后的轨迹；缺失定位段不生成完整公里分段。网络预览坐标不是可累计的跑步轨迹。室内可以直接计时，跑步机距离由用户填写，并标明手动来源。

Keep 官方介绍包含 GPS 后台语音播报、路线等体验：[Keep 官方 App Store 页面](https://apps.apple.com/cn/app/keep-ai-%E8%BF%90%E5%8A%A8%E6%95%99%E7%BB%83/id952694580)。这不公开其定位过滤算法，不能据此声称已复刻其算法。

本批不是完整 Keep 平替：尚无自动暂停、语音播报、自动室内测距、手表协同和路线推荐。国内地图可达性、具体 OPPO 机型的定位/后台限制和长距离测量误差仍需要实地验证。模拟器与浏览器测试不能证明所有手机均无问题。

## 知识库公开与隐藏

Git 忽略规则允许 `knowledge/libraries/nutrition/`、`knowledge/libraries/prisoner/` 进入开源仓库；本地来源配置、环境变量、凭据和新增私有层继续排除。本批只修改规则，没有自动推送这些资料。

隐藏是 UI 可见性控制，不是保密或加密。公开 GitHub 仓库后，任何人都可以获取其中资料；打包进 APK 的资料也可能被提取。动作详情的“原文与配图”按本次修复要求保留，它不提供全库目录。发布资料前仍应核实原文及图片的公开授权。

无消费者的全库浏览、导入表单、笔记阅读和冲突处理四个旧 UI 组件已从应用源目录移除；资料及内部存储/检索不删。源码备份保留在 `D:/UncoverBuildTools/archives/knowledge-ui-retired-20261009/`，可恢复。
