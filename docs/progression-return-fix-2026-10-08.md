# 进阶详情返回保留分类

## 原因

打开动作详情时 AppShell 切换路由，ProgressScreen 被卸载。旧实现把动作分类、路线和搜索条件放在页面内的 useState 中，重新挂载即回到“六艺基础 / 俯卧撑”，而不是用户刚浏览的深蹲。

## 修改

- AppShell 保存进阶浏览状态，详情路由切换不再清除选择。
- 返回保留动作分类、路线、搜索内容与搜索展开状态。
- 列表内容准备好后只恢复一次原滚动位置，不在普通重新渲染时强制跳动。
- 用户主动切换大类仍清空搜索并回到列表顶部。
- 仅本次 App 使用期间保留浏览状态；不修改个人档案、训练阶数、训练记录或验收规则。
- 器械动作库已有自己的返回状态保留，本次不更改其逻辑。

## 验证

`scripts/smoke-progression-return.cjs` 在隔离浏览器中复现旧缺陷：深蹲动作返回后出现“标准俯卧撑”。修复后验证深蹲详情返回、重复打开返回、切换选项卡、跨大类搜索、滚动位置恢复，并核对档案和训练记录不变。覆盖 390px 与 739px。

`scripts/test-progression-navigation.cjs` 防止重新引入页面内部默认分类状态或每次渲染强制滚动。

最终验证：TypeScript 检查通过，344 项自动测试全部通过；完整进阶浏览器回归、图表浏览器回归与“再练一次”端到端检查通过。本次未重新发布安卓安装包。
