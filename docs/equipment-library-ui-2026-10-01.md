# 器械动作库肌群分类与 UI 更新

历史 UI 基线（82 条目 / 23 筛选）。后续等级、112 条目与现代详情的实现见 [器械等级与扩库实施记录](equipment-tier-implementation-2026-10-01.md)；本页的数量和详情说明不代表当前版本。

按确认的深色／荧光绿设计，落地“部位 → 肌群或训练区域 → 动作”三级浏览。首次进入默认胸部／上胸，展示上斜哑铃、上斜史密斯、上斜杠铃卧推及低位向斜上绳索夹胸。现有 82 个动作 ID、图片和详情保留，不增加晋级进度、课表、训练剂量或饮食处方。

## 分类

| 部位 | 肌群／区域筛选 |
| --- | --- |
| 胸部 | 上胸、胸部中区、下胸 |
| 肩部 | 前束、中束、后束、肩袖 |
| 背部 | 背阔肌、上背肌群、竖脊肌 |
| 腿部 | 股四头肌、腘绳肌、臀肌、内收肌群、腓肠肌、比目鱼肌 |
| 核心 | 腹直肌、腹斜肌、核心稳定 |
| 手臂 | 肱二头肌、肱三头肌、肱肌、前臂肌群 |

共 23 个细分筛选，各部位另有“全部”。显式逐 ID 标签位于 `src/data/equipmentLibrary.ts`，不根据旧目录里的宣传性描述自动猜测。多肌群动作可匹配多个相关筛选，每个结果列表按动作 ID 去重；“全部”保持原始 18／13／13／14／10／14 项，总数仍为 82。

胸部筛选表示训练区域侧重，不表示三块独立肌肉，也不提供“内胸／中缝”独立肌肉分类。[胸大肌结构综述](https://www.ncbi.nlm.nih.gov/books/NBK525991/)区分锁骨部与胸肋部；[胸大肌三维结构研究](https://pubmed.ncbi.nlm.nih.gov/19291757/)说明其区域结构。筛选不能推断某动作只激活某一区域，主辅肌贡献随技术、机型与个体变化。核心稳定不冒充可从表面看见的独立肌肉；低杠深蹲不直接标为腘绳肌主训练。

本次只整理浏览分类和卡片短标签，不声称已重写或完成原书关联指导正文的现代科学审核。

## 界面与交互

- 保持共享 `progressPageLayout` 的 440px 最大画布、16px 内容边距和原底部导航；窄屏分类横向可滚动。
- 部位标签、区域标签分别使用荧光绿主选中与橄榄绿次选中，移除旧的大数字分类块。
- 矢量人体简图高亮当前区域，使用适合部位的正／背面视角；是导航示意，不是医学解剖图。深层核心以虚线覆盖区域表示，非深层肌肉切面。
- 保留完整比例的单张 100 × 75 缩略图，详情及放大图不变；卡片展示精简肌群和器材标签。
- 器材底部筛选支持哑铃、杠铃、史密斯、固定器械、绳索、自重器材、辅助器材，与当前肌群取交集，并显示实际数量。
- 器材按照真实类型及合并条目的有效变式打标签；不沿用旧目录把绳索、哑铃等误归“训练器材”的概括。合并条目中的图片仍只代表明确标注的一个变式。
- 搜索覆盖所有部位，包含中英文名称、肌群和器材；搜索时隐藏局部肌群示意，明确“搜索全部部位”，避免把其他部位的结果误呈现为上胸动作。器材限制仍生效。
- 返回详情保留筛选与纵向滚动位置。只保留当前进程的浏览状态，不修改用户档案、训练记录或联网授权。
- 空结果可清除筛选。切换部位／肌群重置不适用的器材选择。
- 使用跨原生／Web 的 `aria-selected`、`aria-checked` 和 `aria-expanded`；减少动态效果时禁用转场，正常设置使用既有轻量显现动画。
