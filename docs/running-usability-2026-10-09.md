# 跑步可用性调整 · 2026-10-09

本次只调整跑步模块及相关历史展示，不引入第三方定位 SDK、账号或收费服务。开发与发布分开：本轮未上传生产安装包。

## 操作规则

- 户外跑直接开始计时，不等待坐标，也不以精确位置权限、系统定位开关、35 米精度为起跑前提。拒绝位置权限时可以开始、锁屏计时、暂停、继续和保存。
- 室内跑不请求位置、不显示虚假地图轨迹；结束时暂停计时，可填写跑步机距离，也可留空只保存用时。没有未经校准的步幅估算。
- 结束改为点击并确认，移除必须长按的隐藏操作。距离表单适配软键盘；暂停失败时不进入宣称“已暂停”的表单。
- 跑步表单及今日页外层滑动容器都让按钮响应键盘打开时的点击，不把第一次保存点击仅用于关闭键盘。
- 修正原生暂停接口返回值：`startService` 的 `ComponentName` 不能通过 Expo 桥序列化，动作接口明确返回 `Unit`，不再出现“已暂停但 JS 报错”的状态。
- 距离未测得显示 `—`，保存为缺失值并标记 `unmeasured`，而不是虚构 0 公里。手填距离标记 `manual`。
- 定位只覆盖部分路程时标记 `runDistancePartial`，不按缺失时间和部分距离计算误导性的全程平均配速。

## 定位和计距

原生预览和户外录制均可订阅系统 GPS、网络和 Android 12+ 可用的系统融合提供者；融合不是 Google Play 服务 SDK。

新鲜网络坐标可移动地图，但不作为连续跑步计距证据。缓存位置仅用于地图，不参与计距。GPS 或系统融合的实时有效坐标可以记录距离；浏览器使用其定位接口返回的坐标。

35 米、15 秒、12 米/秒、30 秒断点与移动噪声过滤仍是计距工程参数，**不是启动计时条件，也不限制有效地图位置的展示**。过滤不能保证里程达到专业测绘精度；误差范围也不是每个点都会偏离同一方向。暂停、进程恢复、长断点、来源切换均分段，不能连直线补造缺失路程。

定位错误与计时/存储错误独立：定位失败不暂停计时；草稿写入失败仍暂停以保护记录。原生以单调时钟计时、原子文件保存草稿；保存重试复用同一记录 ID，不重复添加。

## Android 服务与分发边界

Android 14+ 使用声明了子类型的 `specialUse` 前台服务运行用户主动开始的持续训练计时；位置权限和系统开关满足要求后才增加 `location` 类型并订阅位置。没有用虚假数据同步任务或不需要的传感器权限规避位置限制。

官方说明：[前台服务类型](https://developer.android.com/develop/background-work/services/fgs/service-types)、[启动前台服务](https://developer.android.com/develop/background-work/services/fgs/launch)。`specialUse` 如将来提交 Google Play，需要用途声明及审核；本地验证不等于获得商店审核批准。

本轮更改了原生接口和清单，旧 APK 不能仅靠 JavaScript 热更新获得新行为，手机必须安装包含本次改动的完整新版安装包。

## 验证入口与限制

本轮最终验证：TypeScript 检查通过；全项目 404 项自动测试通过；隔离浏览器完整跑步回归通过；包含当前源代码的独立调试 APK 在 Android 15 / API 35 模拟器完成原生回归。模拟器无定位授权且系统定位关闭时，前台服务与锁屏计时仍运行；室内键盘打开时一次点击即可保存；户外定位回调、暂停、切页、锁屏、进程恢复、三类记录保存、数据页联动与重启不重复均通过，未发现原生/JS 致命异常。

独立离线 QA 副本使用包内 JS，关闭开发服务依赖及该副本的 Expo 更新加载；生产配置没有因此关闭更新。它使用本地调试签名和测试数据，不是可覆盖用户正式安装包的发布版本。浏览器及模拟器夹具从不清理用户实际档案。

- `scripts/test-running.cjs`、`scripts/test-running-location.cjs`：计距、来源、断点、未知距离、手填距离、拒绝定位仍可起跑、草稿/保存错误和恢复。
- `scripts/smoke-running-map.cjs`：隔离浏览器存储，测试地图交互、短屏布局、拒绝位置仍可计时保存、室内模式、输入校验、数据页联动。坐标/瓦片为测试夹具，不进入产品实现。
- `scripts/smoke-running-android.cjs`：仅允许模拟器，验证真正的 Android 服务、权限拒绝、系统定位关闭、锁屏、暂停恢复、注入 GPS 回调、进程恢复、原生草稿与 SQLite 历史。

没有连接用户 OPPO，也没有在用户室内或真实跑道实测。模拟器不能验证卫星接收能力、厂商省电策略、实际户外误差和耗电。任何提供者都不返回坐标时，本实现能够计时，但不能凭空提供实际轨迹或自动里程。
