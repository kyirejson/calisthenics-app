# Uncover 商业级优化方案 v1.0

> 撰写视角：UI 设计师 + 长期坚持街健练习者

## 0. 一句话诊断

**Uncover 把《囚徒健身》的"训练计划层"数字化得比所有竞品都好，但它现在是一个"内容工具"，还不是"训练陪伴系统"——训练日它缺"教练感"，非训练日它缺"进步确认"，长期它缺"留存钩子"。**

现状评分（满分 5）：

| 维度 | 评分 | 评语 |
|---|---|---|
| 体系忠实度 | ★★★★★ | 23 终式 + 五大日程 + 验收规则，比原著更严谨（两次达标是好的产品化） |
| 信息架构 | ★★★★☆ | 三 Tab 清晰，设计系统（纸/墨/柠檬绿）统一且辨识度高 |
| 训练日体验 | ★★★☆☆ | 有计时器和反馈环，但无视频、无语音报数、无里程碑庆祝动效 |
| 非训练日体验 | ★★☆☆☆ | 没有训练历史页、没有进步曲线、没有周报——"今天没练"的用户没有理由回来 |
| 留存机制 | ★☆☆☆☆ | 无 streak、无通知、无挑战、无恢复打卡——留存基础设施为零 |
| 商业化 | ☆☆☆☆☆ | 完全免费，无付费墙设计、无数据导入/云备份 |

行业基准：健康健身类 D1 ≈ 25-35%、D7 ≈ 10-15%、D30 ≈ 3-8%。**达标线：D1≥30%、D7≥12%、D30≥5%。** 当前 Uncover 没有任何留存基础设施，预计 D7 会低于 5%。

## 1. 三路调研核心结论

### 1.1 对标主流平台（Keep / NTC / Freeletics / Hevy / Whoop 等）

**商业级必备十件事**（按重要性）：训练记录器+历史 → 自动 PR 检测与庆祝 → "今天练什么"排程 → ≤8 步 onboarding 即出个性化计划 → 休息计时器 → Streak + 周报 → 进度可视化（容量/体重/照片）→ HealthKit / Health Connect 同步 → 桌面小组件 → 克制的提醒通知。

**关键行业事实**：
- Keep 靠实体奖牌赛事（报名 19-50 元、完赛寄实体牌）累计收入约 5 亿元，但 MAU 三年跌 27%——纯内容订阅撑不起商业模型，装备与赛事才是现金牛。
- Hevy（1000 万用户）证明"记录器 + 低价年费 + 终身买断"模型：免费层慷慨，Pro $23.99/年、终身 $69.99；**记录本身绝不能收费**（MyFitnessPal 把条码扫描入付费墙被全网声讨）。
- Freeletics 验证"课后三键反馈 → 下次课调整"的自适应环是 AI 教练的最小可行形态，无需 LLM。
- 动作视频纠错（pose detection）2026 年仍不达生产级，不要投入。
- 帕梅拉在 B 站的火爆本质是"用户要的不是更多视频，而是'今天练哪个'的编排"——Uncover 已经有编排，这是天然优势。

### 1.2 街健垂直竞品（Thenx / Caliverse / TMA / Calisteniapp）

- **最强设计**：Caliverse 的"干净次数解锁门禁"——记录达标才放行，"没有 3 组干净引体就不给升级"，把进度变成"挣来的"；The Movement Athlete 的游戏化技能地图（可预览未解锁技能、"你在旅程中的位置"总览）。
- **普遍弱点（机会）**：验收靠自报、演示只有循环视频（无慢放/分步/错误对比）、计时器是 HIIT 思维而非技能思维（缺长休息倒计时与静停秒表）、进步可视化只有次数和体重（街健文化本质是"力量体重比"文化）、第一代街健品牌 App（Bar Brothers 等）已全部消亡——**赛道上没有强者，只有旧地图**。
- 国内"囚徒"类小 App 有十式列表和"完成训练方可出狱"叙事，但无视频、无验收、无营养——Uncover 对它们是降维打击，前提是补齐体验。

### 1.3 《囚徒健身全集》未利用资产（最有价值的 12 项）

| # | 资产 | 出处 | 产品设想 | 难度 |
|---|---|---|---|---|
| 1 | **巩固训练**（Grease the Groove） | 一册11章/三册14章/四册6章 | 卡关动作一键开启"巩固日"，早晚提醒做 1-2 个高质量反复，一周后回归计划。**解决街健最大痛点"卡关"，天然提日活** | 低 |
| 2 | **关节三诀完整跟练** | 二册14-17章 | 独立"今日三诀"10 分钟跟练页（原著有完整处方：桥式1×10s+2×5s→直角式4×5s→扭转式20s/侧 + 各自升级链），休息日/久坐提醒触发 | 中 |
| 3 | **心灵·六大恶魔弃训干预** | 二册21章 | 断练 3 天推送对应"恶魔"识别卡（没时间→5分钟最小课；泄气→回退一式重建势头），原著文本就是现成文案库 | 低 |
| 4 | **起居有时·睡眠打卡** | 二册18章 | 固定熄灯/起床时间、睡眠时长并入恢复评估——原著"恢复占 96%"的核心 | 低 |
| 5 | **疗伤八法向导** | 二册20章 | 伤后分步向导：急性期 P.R.I.N.C.E. 清单 → 恢复期"练健侧"替代计划 → "不痛前提下轻柔多次练伤处"自动降阶到同系列前三式 | 中高 |
| 6 | **PARC 验收 + 三规六矩** | 三册10/12章 | 爆发六功改为"10 试 9 成"四要素自评；处方按每组≤3 次、日总量 6/12/18 输出 | 中 |
| 7 | **挑战 20 磅年度挑战** | 四册额外章节一 | 年度目标事件：6 策略引导 + 月度体重/围度/照片进度墙 + 里程碑解锁 | 中 |
| 8 | **增肌模式训练处方** | 四册2章 | 目标"增肌"时组次改为 12-20+ 次降阶动作 + 训后终结组，限 2 组——现有增肌目标只有营养侧 | 中 |
| 9 | **十二金刚场景替代** | 四册额外章节二 | "没有单杠？""膝盖不适？"场景筛选 → 映射原著 12 组无器械替代关系 | 低 |
| 10 | **控重变强模式** | 四册6章 | 女性/体重受限路线：低次数高频、力量涨围度不涨 | 中 |
| 11 | **金科玉律热身** | 一册11章 | 热身按当天主训动作自动取同系列低阶式生成"20 次+15 次"两组，替代通用四段热身 | 低中 |
| 12 | **排难解忧·停滞诊断器** | 一册11章 | 连续两周未达标弹四问诊断（体重涨了？休息够吗？凑次数？生活方式脏？）→ 对应处方 | 低中 |

**旧产品设计稿（小程序 V1.1）里规划了但没做的工程缺口**：训练历史周报、训练中疼痛入口、断练恢复流、"只有 15 分钟"缩短课、主动退阶按钮、升级原因解释、单侧动作左右分开记、课前 check-in、数据导入（现在只能导出不能导入！）。

**三处"不像原著精神"需要修正**：
1. 四周基准/容量/强度/减载是杠铃思维移植——原著明确说体操"无需降载周期"。建议减载周改造成原著的"巩固训练 + 三诀周"，叙事更顺。
2. 爆发六功用次数验收是方向性错误——原著用 PARC（10 试 9 成）论证"快速和力竭背道而驰"。
3. 营养的现代四餐+热量循环与原著"三餐规律、间隔 4 小时、睡前微饿"并存即可，但可增加"狱中饮食模式"作为可选极简哲学。

## 2. 设计师 + 练习者诊断：三个本质缺口

**作为每天练街健的人，我每天打开训练 App 的理由只有两个：**
- 训练日：它是"秒表 + 教练 + 账本"——计时、报数、下一个动作、今天练什么；
- 非训练日：它是"进步确认器"——看进度条、看离下一式还差几次、看曲线。

**Uncover 现状对照：**
- 训练日的"教练感"缺了三样：**视频演示**（书截图 ≠ 会动的人）、**语音报数与倒计时**（户外手机架地上、戴手套，强光下看不见屏幕）、**里程碑庆祝**（第一次标准引体是街健人一年中最重要的一天，现在 App 只默默打勾）。
- 非训练日的"进步确认器"完全不存在：没有训练历史页、没有静停秒数/次数曲线、没有力量体重比、没有周报。平台期用户（卡在进阶团身半年的人）看不到"次数没涨但保持秒数涨了"，就会流失。
- 长期留存钩子为零：没有 streak、没有挑战、没有通知。街健用户的流失点非常明确：新手死在"第一个标准引体前的 2-3 个月"（0→1 太长），中期死在平台期，冬天死在户外中断，长期死在孤独。

**结论：先补"陪伴层"，再谈商业化。**

## 3. 优化方案（四期路线图）

### P0 体验地基（4-6 周）——不做这些就谈不上商业级

| # | 功能 | 做什么 | 为什么 | 难度 |
|---|---|---|---|---|
| P0-1 | **训练历史页** | 按日期列出全部训练记录（课程名/时长/完成度/质量反馈），周/月视图 | 数据沉淀是留存第一性原理；没有记录器的健身 App 只是视频播放器 | 低 |
| P0-2 | **进步曲线** | 按"艺"汇总三条曲线：最大次数、静停秒数、力量体重比（次数×体重）；首个标准动作自动生成纪念卡 | 街健文化本质是力量体重比文化；平台期用户需要副线反馈 | 中 |
| P0-3 | **验收门禁点亮** | 验收达标自动点亮下一式 + 进度条"距下一式标准还差 X 次" + 升级原因解释文案 | 学 Caliverse"不干净不放行"，把已有验收资产变成游戏；投入极小 | 低 |
| P0-4 | **技能计时器 + 语音** | 静态保持秒表、组间 2-4 分钟长休息倒计时、语音报数"准备—开始—还剩 10 秒"、组间拉伸提示 | 训练中的随身教练；户外场景（手机架地/戴手套/强光）刚需 | 中 |
| P0-5 | **里程碑与 PR 庆祝** | 首次解锁变式、首次完成课程、连续打卡 7/30/100 天——全屏庆祝动效 | Hevy 验证的最低成本多巴胺来源 | 低 |
| P0-6 | **Streak + 周报** | 连续打卡天数（训练日 + 三诀日合并计入）；周报卡片：完成数/容量/保持秒数变化/下周重点 | 留存贡献最大的两件套；周报内容直接用原著话术 | 低 |
| P0-7 | **断练恢复流 + 疼痛入口** | 断练 ≥3 天触发六大恶魔识别卡；≥14 天重新确认状态从轻安排；训练中"出现不适"可点按进入疗伤八法向导（P1） | 原著心灵章是最现成的留存文案库；弃训干预直接服务 D30 | 低 |
| P0-8 | **数据导入** | JSON 备份可导入恢复——换机/误清除用户刚需，现在只有导出 | 工程缺口，顺手补齐 | 低 |

**P0 的信息架构调整**：底部 Tab 从 3 个变 4 个——**今日 / 进阶 / 数据 / 我的**。"数据"页承载 P0-1 历史与 P0-2 曲线 + 周报 + 里程碑墙。进阶页保持技能树本体。

### P1 差异化护城河（6-10 周）——竞品抄不走的原著灵魂

| # | 功能 | 做什么 | 为什么 | 难度 |
|---|---|---|---|---|
| P1-1 | **巩固训练模块** | 动作详情加"卡关？开启巩固日"→ 早晚各 1-2 次高质量反复提醒，一周日程独立于主计划，结束后回归 | 街健第一痛点的原著解法；把 App 从"计划工具"变"日常陪伴"，日活杠杆 | 中 |
| P1-2 | **三诀跟练** | 独立 10 分钟跟练页：三诀各自升级链 + 保持秒数处方 + 跟练计时；休息日自动推荐 | 久坐人群关节刚需；目前只有文字弹窗是最大落差 | 中 |
| P1-3 | **视频演示** | 60 式各配短视频：标准示范 + 慢放 + 典型错误对比；自拍或与街健 UP 主合作分成 | 所有竞品的公认硬伤都在这；有视频的进阶体系体验是代际差 | 高（内容制作） |
| P1-4 | **疗伤八法向导** | 伤后分步流：急性清单 → 练健侧替代计划 → 自动降阶到同系列前三式 | 伤是自重用户第一大弃训原因；原著框架 + 现有十式降阶数据天然支持 | 中 |
| P1-5 | **停滞诊断器** | 连续两周未达标 → 四问诊断 → 处方（回退一式/换日程/开巩固日） | 把"降级"从挫败感变成原著式智慧叙事；排难解忧四法直接文案化 | 低中 |
| P1-6 | **PARC 爆发验收** | 爆发六功改为"10 试 9 成"自评 + 每组≤3 次、日总量 6/12/18 处方 | 修正方向性错误，让爆发六功真正可练 | 中 |
| P1-7 | **十二金刚场景入口** | 动作库按"没有单杠/膝盖不适/出差酒店"场景筛选替代动作 | 无器械用户刚需，数据已在库，只差关系层 | 低 |
| P1-8 | **原著热身与巩固周** | 热身按当天主训动作生成"同系列低阶式 20+15"；减载周改名"巩固周"并植入三诀+巩固训练 | 修正原著精神偏差 #1 | 低中 |

### P2 商业化（10-16 周）——先有留存再谈收入

| # | 项 | 内容 | 定价锚点 |
|---|---|---|---|
| P2-1 | **免费 / Pro 分层** | 免费：全部六艺进阶、验收、每日计划、基础记录；Pro：无限训练历史与曲线、巩固训练模块、三诀跟练全处方、视频演示、高级周报。**记录本身永远免费** | Pro 对标 Hevy：国内 30-40 元/年，**终身买断 128-198 元**（街健人群与 Hevy 用户重合，厌恶订阅、终身买断转化极高） |
| P2-2 | **季度挑战赛 + 实体奖牌** | "30 天引体挑战""百次俯卧撑""首个标准引体纪念牌"：报名 9.9-29.9 元，完赛寄实体牌 + 限定编号；晒牌对接小红书 | Keep 奖牌业务 5 亿营收的模式迁移，技能"首成"比跑步距离更有晒的价值 |
| P2-3 | **训练卡分享** | 一键生成训练卡图片（今日六艺成绩 + 进度条 + streak）分享微信/小红书 | 借外部生态拉新，不自养社区（Madbarz 前车之鉴） |
| P2-4 | **付费墙位置** | Onboarding 生成计划的结果揭示页之后；试用期到期前提醒 | 行业转化最优解：个性化结果后放墙 |

### P3 生态与增长（16 周+）

- **Health Connect / HealthKit 同步**：体重双向同步、Workout 回写（2026 年不做健康生态同步会被商店编辑扣分）。
- **桌面小组件**：streak 计数 + 今日课程 + 一键开练 deep-link。
- **提醒通知三类**：计划时间提醒、streak 危机提醒（20 点未练）、周报到达——不过度推送。
- **"刑期"叙事产品化**：十式完成度 = 刑期进度、每周减刑、毕业"出狱证书"——中文语境独有的叙事资产，竞品抄不走。
- **场地标签 + 单杠地图**：动作标"无器械/单杠/平行杠"；GPS 跑步页加附近单杠点位众包。
- **可选"狱中饮食模式"**：原著三餐规律哲学作为营养的极简可选模式，与现四餐制并存。

### 不做清单（同样重要）

| 不做 | 理由 |
|---|---|
| 大而全课程库 | Keep 1.3 亿用户的内容护城河无法正面打；20% 深度内容覆盖 80% 目标人群 |
| 自研硬件 | 资本游戏；接健康平台数据即可 |
| 泛社区 feed | Keep 社区 MAU 下滑证明运营成本极高；只做轻社交（分享卡/战队挑战） |
| AI 视频动作纠错 | pose detection 未达生产级；诚实做"自适应教练"而非"AI 纠姿" |
| 重饮食（食物库/条码） | MyFitnessPal 十年积累无法追赶；保持"体重/围度记录 + 目标"轻量 |

## 4. 设计系统演进（UI 设计师视角）

现有纸/墨/柠檬绿系统辨识度高，无需推翻，按以下规则扩展：

1. **节奏语言**：深色 hero 开场 + 纸色内容延续，是全 App 的既有节奏。新增页面遵循：数据页顶部深色总览卡（本周容量/streak/里程碑墙），下方纸色列表。
2. **庆祝动效**：柠檬绿作为唯一"成就色"——解锁时全屏墨色遮罩 + 柠檬绿技能图标放大 + 一句话（用原著话术："这一式，你挣来了。"）。克制、有仪式感、不卡通。
3. **曲线设计**：三条曲线（次数/秒数/力量体重比）用墨色细线 + 柠檬绿当前值点，避免彩虹图表；里程碑在曲线上以柠檬绿圆点标注。
