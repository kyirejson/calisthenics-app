## 已实施

- 删除用户指定的“按自己的节奏轻松跑或快走。”和“运动时请勿操作手机 · 未授权定位不记录路线或配速”。权限拒绝时仍保留必要的状态反馈。
- 使用与进阶、数据、饮食一致的暗色画布：最大宽 440px，左右内边距 16px；地图宽高比 1.38，不再固定高度。
- 按模板强化里程、计时与配速，增加原生 SVG 图标；暂停/继续为描边按钮，结束为荧光主按钮。
- 增加距离/时长目标与真实进度。自选目标单独保存，不改训练计划；不把示意图的 5km 当成默认课程或已完成里程。
- 目标弹窗含校验、快捷选项、清除/恢复课程目标、保存失败提示；适配短屏滚动与键盘避让。
- 未授权时显示中性的定位网格和“开启定位”；没有虚构街道和模拟跑过的路线。
- 路线自动适配完整外接框，不只盯住末点；手动缩放后可以一键回到完整路线。支持经度 ±180° 邻近点的正确投影。
- 拒绝无效坐标、无效或大于 35m 的精度；暂停移动不增加距离，继续后的第一点不形成跨暂停跳跃段。
- 计时按实际运行区间累计，不靠每秒回调次数凑时长；保存失败保留数据，继续记录会重建已移除的定位订阅。
- 长轨迹降采样保留首尾，避免丢弃前半段；重复保存有即时锁，离页/结束清理订阅。
- 真实底图失败时明确显示失败与重试，仍能展示已有 GPS 路线，避免无解释的空白。

## 未解决的真实服务和真机边界

实际联网测试中，现用 Esri 开发图源在这台电脑上返回 403，浏览器报告 `ERR_BLOCKED_BY_ORB`；因此不能把模拟瓦片测试写成“真实地图已稳定可用”。同供应商文档中的另一公开端点也返回 403；本次没有继续切换服务商、购买授权或填入第三方密钥。

地图网格是未定位/底图失败的界面底层，不是实际道路。正式地图接入需要单独确认供应商授权、国内道路覆盖与坐标系统；不能仅凭无需密钥的旧地址就判断可商业使用。现代 ArcGIS 底图接口有明确的认证字段。[Esri 官方底图接口](https://developers.arcgis.com/rest/basemap-styles/arcgis-darkgray-base-webmap-get/)。

当前使用前台 `watchPositionAsync`，没有后台任务、后台权限或前台定位服务实现；锁屏/切到其他应用后的路线连续性未获得保证。计时能根据运行区间补算，不代表后台 GPS 点能补算。[Expo Location 官方文档](https://docs.expo.dev/versions/latest/sdk/location/)。

没有做户外安卓真机距离/漂移、定位重获、锁屏、进程被杀和电耗验证。失去 GPS 后的长间隔、异常高速点与恢复断线段需要真实场景进一步测量，本轮不宣称专业跑步追踪能力完整通过。
