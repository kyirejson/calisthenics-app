# 器械进阶页：推荐等级、扩库与现代详情实施记录

日期：2026-10-01。基于 [S–C 调研报告](equipment-exercise-tier-research-2026-10-01.md) 实现，仅影响器械动作库、对应详情及其测试。没有修改训练规划、饮食建议、用户阶数／训练记录，没有上传或正式发布。

## 已实现

- 82 个原 ID 的推荐等级与报告逐项一致；S–C 为健康成人以增肌选动作为默认场景的应用编审优先级，不是难度、技能晋级、官方科学榜单或安全认证。
- 增肌推荐放在动作卡片内（“增肌 S / A / B / C”），不另设等级筛选；各肌群及全局搜索结果按 S → A → B → C 排序。等级解释留在详情页。
- 肌群与器材交集筛选；关键词跨部位搜索，同时保留器材限制。肌群没有“全部”选项，切换部位自动选择第一个实际肌群，胸部显示“上胸 / 中胸 / 下胸”。空结果可清除筛选，详情返回保留筛选和滚动位置。
- 5 个混合条目拆成精确变式，新增 25 项报告候选，共 112 个浏览条目。它们不代表 112 种独立运动模式或用户已掌握技能。
- 28 个肌群／功能筛选，补肩胛控制、上斜方肌、髋外展、胫骨前肌、腕伸；示意图相应补部位高亮，仍是表面区域示意而非医学解剖图或深肌分离图。
- 112 个条目各具设置、执行、呼吸与收尾，以及两项问题／纠正。不再默认展示书籍关联章节，不用原书章节冒充现代变式的完整操作。
- 详情展示推荐条件、功能用途及可展开的技术／评级依据；D / R / P 依据类型与等级分开。控制类 B 与力量专项 B 保留相应用途说明。
- 清理旧通用指导、夸大肌群描述、拆分动作中的器材错标。目录与新增元数据、分类定义各有单一来源；书籍文本导入器不再覆盖现代目录。

## 来源与内容边界

基础操作资料沿用已核验的 ACE、NASM、Catalyst、Mayo 及对应器材厂商，研究和推荐理由来自调研报告。技术资料页面未覆盖的角度、支撑或器材变式明确为应用编审适配，而不是假称网页原文逐字指导。厂商资料仅用于机器结构与操作对应，不采纳“最佳激活、零风险、伤害预防”等营销保证。

本次另外核对并用于相关操作方向：

- [ACE 肘靠体侧绳索内旋](https://www.acefitness.org/resources/everyone/exercise-library/351/rotator-cuff-internal-rotation/)。
- [Catalyst 反向卷腹](https://www.catalystathletics.com/exercise/320/Reverse-Crunch/)。
- [Catalyst EZ 杠反握弯举](https://www.catalystathletics.com/exercise/873/Reverse-EZ-Curl/)。
- [AAOS 腕伸与前臂支撑](https://orthoinfo.aaos.org/globalassets/pdfs/a00790_therapeutic-exercise-program-for-epicondylitis_final.pdf)：仅参考方向和支撑，不复制肘病康复剂量。
- [ACE 上斜划船操作示例](https://www.acefitness.org/certifiednews/images/article/pdfs/ACEShoulderStudy.pdf)：用于支撑和水平拉模式，不以肌电给增肌排行背书。
- [Hammer Strength 踝背屈机器](https://www.lifefitness.com/ja-jp/catalog/strength-training/plate-loaded/plate-loaded-tibia-dorsi-flexion)：只限定专用设备，不建议临时绑脚负重。

内容已从无差别通用提示改为动作特有指导，但没有完成合格教练／运动科学人员逐项签审，也没有现场验证每个机型。自动化验证不能证明运动技术、增肌评级或生成图片已获专业认证。正式发布前仍需这些内容验收。

## 图片状态

原 82 套独立写实生成图与缩略图保留，另用内置 image_gen 补齐新增 30 套。目前全部 112 个条目均有独立彩色人物示范，完整图 1448 × 1086、缩略图 480 × 360，单人、单画面、穿鞋，不复用其他动作照片。图片属于写实生成示范，不是真人实拍，也不代表具体厂商机型的操作认证。

逐张做基础视觉核对，对上斜推胸角度、侧平举器械、踝背屈负荷接触、牧师弯举手柄连接重做修正。死虫式选择明确标注的起始位图，避免不清晰的对侧肢体关系；后续运动按正文指导。辅助引体图片明确展示机器变式，不冒充弹力带变式。失败时仍使用标明“部位示意”的回退，不把加载错误当示范图。
