# 饮食页精简与体重图表 · 2026-09-28

仅修改本地界面与验证脚本，未提交、推送或发布更新。此文已合并用户后续提出的删除快捷记餐、晚餐建议与新增体重曲线要求，不代表生产上线验收。

## 当前布局

- 摄入汇总下方两个并排入口：拍照估算 / 营养助手。助手替换原搜索入口。
- 今日饮食仅显示确认保存的实际记录。手动搜索、自定义食物、添加、编辑、删除仍在“管理 → 添加饮食记录”中。
- 删除记录完整度大卡片、训练与饮食及训练时段、近 7 天复盘、整日推荐菜单、页底常驻隐私/医疗说明。
- 删除整块下一餐建议，不只是晚餐标题；早餐、午餐、加餐建议也不会在主页面重新出现。
- 删除快捷记餐的常用/最近切换、复用入口、收藏/删除收藏按钮。已有保存数据保留，不作清空。
- 删除下一餐专属状态、操作、菜谱详情/食材详情弹窗、独立草案弹窗及闲置样式。营养助手仍保留主动调用配餐及草案确认能力。
- 餐次核对只放在主动打开的记录管理中。拍照与助手内的联网同意、估算标记、健康限制、保存失败提示保留。
- 体重趋势为深色卡片、荧光绿折线与淡渐变；7 / 30 / 90 天切换、周期均重、实测天数、日期坐标和点选记录。前后箭头提供可访问的替代操作。

## 数据边界

- 摄入汇总仍只采用已保存营养快照；删除界面不新增或删除摄入。
- 助手中的配餐只修改推荐，显式确认后才保存，不自动记为已吃。
- 增加、修改或删除记录后的餐次完整度失效规则不变。
- 体重图表只用真实称重记录，不用档案体重填充，不补齐缺失日期，不造示范趋势。按真实日历间隔布点，以直线连接实测点，不做曲线过冲。
- 同一天采用最后有效值；无效日期、非数值、超出 30–300 kg 以及未来记录不进入当前趋势。均重按所选周期的有效实测天数计算。
- 单点只显示一个点，不显示趋势连线；零记录显示空状态和“—”，不显示 0 kg。
- 保存今天体重替换当天记录，失败保留输入与旧图表，可重试；不自动覆盖档案中的饮食计算体重。
- 数据清洗规则已在图表、周均重与建议计算间统一，重复日期不能凑够周对比所需天数。
- 复用既有淡入/轻上移动效；尊重系统减少动效偏好。Web 点击与手机触摸分别转换为图表内坐标。
